- 每个工具文件在末尾通过 `registry.register(...)` 显式声明 name、toolset、schema、handler、check_fn 和 emoji，由 registry 统一管理工具发现与路由。
- handler 函数统一接收 `(args: dict, **kw) -> str` 签名，返回 JSON 字符串；错误路径统一调用 `tool_error(message, success=False)` 构造结构化失败响应。
- 对外部系统调用采用 async 协程 + `_run_async` 同步包装的模式，使工具既能在线程内运行也能复用已有事件循环。
- 敏感输入在进入持久化层前通过 `redact_sensitive_text(..., force=True)` 脱敏（如 Kanban 的 summary/result/reason/body）。
- 外部命令/URL/实体 ID 等用户可控字符串在进入网络或文件系统前使用正则白名单校验（如 entity_id 格式、service domain 格式、blocked domains 列表）。
- 可选/重型依赖采用延迟 import（如 kanban_db、sparkii_state、aiohttp 在函数体内导入），保证模块可在无依赖环境中正常 import。
