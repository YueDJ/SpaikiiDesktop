Sparkii 的工具集通过 `tools/registry.py` 中心注册表进行统一管理。启动时 `discover_builtin_tools()` 使用 AST 扫描 `tools/` 目录下所有 `.py` 文件，识别包含顶层 `registry.register()` 调用的模块并自动导入，扫描结果按文件的 (mtime_ns, size) 缓存至磁盘以避免重复解析。每个工具模块在导入时调用 `registry.register()` 声明名称、所属工具集（toolset）、JSON Schema 与处理函数；运行时 `model_tools.py` 查询注册表动态生成 LLM 可见的工具定义。

工具集配置通过 `sparkii tools` CLI 子命令交互式管理。该向导按平台与工具集维度展示可用工具，用户可启用或禁用特定后端（如浏览器供应商、TTS 引擎、搜索服务）。配置结果写入 `config.yaml` 的 `tools` 和 `toolsets` 节。启用或禁用后需调用 `invalidate_check_fn_cache()` 刷新工具可用性缓存，确保下一次对话轮次加载正确的工具集。

插件系统（`plugins/` 目录）为工具注册提供扩展点：第三方或可选工具通过插件机制自注册到同一个 registry，无需修改 `tools/` 核心代码。`sparkii plugins enable/disable` 命令管理插件生命周期，插件的工具在注册表中与内置工具同级竞争。

Skills Hub（`tools/skills_hub.py`）提供技能的搜索、安装、浏览与发布能力。CLI 命令 `sparkii skills search/install/list/publish` 调用该模块，支持 GitHub 源与可选技能目录。安装的技能通过 `HubLockFile` 跟踪来源哈希，`quarantine` 目录隔离待安全扫描的技能，审计日志记录所有安装操作。`blueprints.py` 模块将技能元数据中的 `metadata.sparkii.blueprint` 块桥接到 cron 定时任务系统，使带调度声明的技能可自动注册为建议任务。
