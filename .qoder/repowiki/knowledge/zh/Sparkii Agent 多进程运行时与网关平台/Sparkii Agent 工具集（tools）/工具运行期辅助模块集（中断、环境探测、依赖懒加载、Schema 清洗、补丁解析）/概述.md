工具运行期辅助模块为工具执行提供横切关注点的支撑能力。

工具注册表（`registry.py`，约 1002 行）是整个工具系统的核心枢纽。`ToolRegistry` 类维护已注册工具的名称、Schema、处理函数与工具集映射。`discover_builtin_tools()` 通过 AST 扫描识别含顶层 `registry.register()` 调用的模块，扫描结果按 (mtime_ns, size) 缓存到磁盘避免重复解析。`tool_error()` 函数统一错误格式，错误体有 2048 字符上限（`_MAX_TOOL_ERROR_CHARS`），超出自动截断；JSON 结果中的 `error` 字段在 dispatch 边界同样受限（`_bound_json_error_result`），防止重试累积导致上下文膨胀。

中断机制（`interrupt.py`）实现线程级中断信号，通过 `_interrupted_threads` 集合（`threading.Lock` 保护）跟踪被中断的线程标识。Agent 在 `run_conversation()` 开始时存储执行线程 ID，工具通过 `is_interrupted()` 检查当前线程状态——无需参数，天然线程隔离。`_ThreadAwareEventProxy` 提供向后兼容的 `Event` 接口，将 `is_set()`/`set()`/`clear()` 映射到 per-thread 状态。`clear_current_thread_interrupt()` 在用户批准命令后清除陈旧中断位，防止误杀刚批准的子进程。支持 `SPARKII_DEBUG_INTERRUPT` 环境变量启用每次 set/check 的调试追踪。

懒加载依赖（`lazy_deps.py`，约 1219 行）解决可选后端的按需安装问题。`LAZY_DEPS` 白名单映射 dot-separated 特性名到 pip 包规格（如 `provider.anthropic` → `anthropic==0.87.0`），后端模块在首次导入路径顶部调用 `ensure("feature.name")`。安全模型包括：venv 作用域安装（不触碰系统 Python）、持久化目标模式（`SPARKII_LAZY_INSTALL_TARGET` 重定向到可写数据卷，追加到 `sys.path` 末端不抢占已有包）、仅支持 PyPI 包名（禁止 `git+https://`/`file:` 路径）、`security.allow_lazy_installs: false` 可禁用运行时安装。`FeatureUnavailable` 异常在安装失败时提供实际 pip stderr 与修复提示。

后端选择辅助（`tool_backend_helpers.py`，约 312 行）提供 `managed_nous_tools_enabled()`（Nous Tool Gateway 资格检查）、`normalize_browser_cloud_provider()`（浏览器云供应商标准化）、`coerce_modal_mode()`（Modal 执行模式规范化）等共享函数，避免各工具模块重复实现供应商探测逻辑。
