浏览器自动化工具集为 LLM Agent 提供统一的浏览器操作能力，抽象多后端差异，使模型无需关心底层实现。

主浏览器工具（`browser_tool.py`，约 5099 行）通过 `agent-browser` CLI 封装浏览器操作，支持三种后端自动切换：本地 Chromium（默认零成本，通过 `agent-browser install` 下载）、Browserbase/Browser Use 云执行（按 API Key 自动检测）、以及 Camofox Firefox 反检测浏览器（通过 `CAMOFOX_URL` 环境变量激活）。页面快照使用无障碍树（ariaSnapshot）提供文本表示，适合无视觉能力的 LLM。元素交互通过 ref 选择器（`@e1`、`@e2` 等）定位。核心工具函数包括 `browser_navigate`（导航，冷启动最低 60 秒超时）、`browser_snapshot`（页面快照，超过 15,000 字符触发 LLM 摘要）、`browser_click`、`browser_type`、`browser_console`、`browser_eval` 等。每个任务获得隔离的浏览器会话（task_id 维度），自动清理。安全机制包括 SSRF 防护（`url_safety` 模块拦截内网地址）、网站访问策略（`website_policy`）、以及子进程环境变量清理（`_build_browser_env()` 仅传递浏览器所需的 API Key，不暴露完整密钥环）。

CDP 工具（`browser_cdp_tool.py`，约 685 行）暴露原始 Chrome DevTools Protocol 透传能力，作为主浏览器工具的补充出口（escape hatch）。通过 WebSocket 连接浏览器的 DevTools 端点（`BROWSER_CDP_URL` 环境变量或 `config.yaml` 的 `browser.cdp_url`），支持任意 CDP 方法调用，处理原生对话框、iframe 作用域 eval、cookie/网络控制、低级标签管理等主工具未覆盖的场景。支持 `target_id` 参数通过 `Target.attachToTarget` 附加到特定页面。安全复用主工具的 SSRF 防护（`_browser_cdp_private_guard`），私有页面上仅允许 `Browser.getVersion`、`Target.*`、`Page.navigate/reload/stopLoading` 等安全方法。输出通过 `_redact_cdp_output()` 递归脱敏。
