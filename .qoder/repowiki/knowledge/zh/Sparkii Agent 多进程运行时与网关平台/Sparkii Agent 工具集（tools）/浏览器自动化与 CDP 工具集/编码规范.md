- 所有对外暴露的工具函数统一通过 `tools.registry.registry.register(...)` 声明 schema、handler、check_fn 与 emoji，并在 check_fn 中做运行时可用性探测（如 CDP 是否可达）。
- 敏感信息（CDP URL、JS 对话框消息、console 输出、vision 分析结果）一律经 `agent.redact.redact_cdp_url` / `redact_sensitive_text` 过滤后再写入日志或返回给 agent。
- 配置读取采用「config.yaml → 环境变量 → 默认值」的三级回退，并使用模块级 `_cached_*` + `_*_resolved` 标志做一次性缓存，避免重复 I/O。
- 可选/重型依赖（requests、websockets、call_llm、各 provider 类）通过 `try/except ImportError` 或 `__getattr__` 延迟导入，保证模块可在最小环境中被 import。
- SSRF/私有 URL 防护通过 `_eval_ssrf_guard_active` + `_is_safe_url` / `_is_always_blocked_url` 在 navigate、snapshot、vision、CDP Runtime.evaluate 等多条路径上统一检查，失败时返回结构化 tool_error。
- CDP 相关错误消息中的 URL 统一经 `_sanitize_url_for_logs` / `_redact_cdp_error_text` 脱敏，防止 token/userinfo 泄露到日志或 traceback。
