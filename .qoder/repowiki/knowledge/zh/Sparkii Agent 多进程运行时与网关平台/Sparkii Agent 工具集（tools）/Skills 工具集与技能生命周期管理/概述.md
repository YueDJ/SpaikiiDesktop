Skills 工具集管理 Sparkii Agent 的可插拔能力系统，以 SKILL.md 文件为核心载体。`skills_hub.py`（约 4430 行）是 Skills Hub 的底层库，提供 `SkillSource` 抽象基类及其实现：`GitHubSource`（通过 GitHub Contents API 从任意仓库获取技能）、`OptionalSkillSource`（随 repo 分发的可选技能，需手动激活）。Hub 状态管理包括 `HubLockFile`（来源追踪）、`HubAuditLog`（操作审计）、`quarantine` 目录（安全隔离）和 `index-cache`（搜索索引缓存，TTL 1 小时）。路径常量通过 PEP 562 `__getattr__` 动态解析，支持 profile 级覆盖。

`skills_tool.py`（约 2060 行）实现 Agent 可调用的技能工具。`skills_list` 工具采用渐进式披露架构（Tier 1：仅返回元数据，name ≤64 字符、description ≤1024 字符），使用 per-session 缓存避免重复扫描数百个 SKILL.md 文件。`skill_view` 工具加载完整技能内容（Tier 2-3），支持通过 `references/`、`templates/`、`assets/` 子目录按需加载关联文件。SKILL.md 格式兼容 agentskills.io 标准，YAML frontmatter 声明 name、description、version、license、platforms（macos/linux/windows）、prerequisites、metadata 等字段。

`blueprints.py` 将技能元数据中的 `metadata.sparkii.blueprint` 块解析为 `BlueprintSpec`，桥接到 cron 定时任务系统。安装一个带 `blueprint:` 块的技能不会自动调度，而是注册一条建议（suggestion），用户接受后才创建 cron job。这遵循"Extend, Don't Duplicate"设计原则：蓝图即技能、调度即 cron job、共享即现有的 publish/tap/index 路径。
