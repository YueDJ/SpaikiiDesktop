- 所有对外部路径（install_path、file_path、skill name）在落盘前都经过规范化与穿越检测（`has_traversal_component` / `_normalize_bundle_path` / `validate_within_dir`），拒绝绝对路径、`..` 段与 Windows 盘符。
- 敏感或关键状态文件（`.usage.json`、`.bundled_manifest`、lock.json）统一采用 temp file + `os.replace`/`atomic_replace` 原子写入，避免并发中断导致损坏。
- 通过 `contextvars.ContextVar` 传递运行时上下文（如 write origin），使工具在处理同一请求的不同阶段能感知是否处于 background_review fork。
- 外部依赖（如 `agent.skill_utils`、`sparkii_cli.config`、`tools.path_security`）采用函数内延迟 import，避免循环导入并在测试中支持 monkey-patch。
- 安全扫描与 lint 均以纯函数形式返回结构化结果（`ScanResult` / `LintFinding` 列表），由调用方根据 trust level 或 severity 决定 block/allow，而非在扫描器内部硬编码策略。
- Hub 与 sync 层对网络请求统一走 SSRF 白名单（`tools.url_safety.create_ssrf_safe_client`、`is_safe_url`、`check_website_access`），并对 GitHub API 403/429 实施指数退避与 reset 头等待。
