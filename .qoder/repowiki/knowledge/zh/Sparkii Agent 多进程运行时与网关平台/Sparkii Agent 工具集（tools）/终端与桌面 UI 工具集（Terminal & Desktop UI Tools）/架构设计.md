本模块由两类工具组成：
- 命令执行后端：`terminal_tool.py` 是核心，统一封装 local/Docker/Modal/Vercel Sandbox/Singularity/Daytona/SSH 等多种执行环境，通过 `TERMINAL_ENV` 环境变量切换；内置 sudo 密码缓存、危险命令审批（委托 `tools.approval`）、工作目录白名单校验、背景进程改写（`_rewrite_compound_background`）和磁盘用量告警缓存。
- 桌面 UI 工具：`read_terminal_tool.py`、`close_terminal_tool.py`、`focus_pane_tool.py`、`open_preview_tool.py`、`read_preview_tool.py`、`read_window_tool.py` 均注册到 `tools.registry` 并归属 `desktop_ui` toolset，通过 `tools.desktop_ui` 提供的 emitter（由桌面 tui_gateway 在会话启动时注入）向渲染器发送事件（如 `pane.reveal`、`preview.open`、`terminal.read.request`），非桌面环境直接返回 `tool_error`。
- 辅助层：`terminal_hints.py` 基于输出模式匹配为失败命令生成可操作的恢复提示；`voice_mode.py` 独立实现推语录音（sounddevice + Termux:API 双后端）、静音自动停止、思考音提示与 TTS 播放，并通过 `detect_audio_environment` 探测 SSH/容器/WSL/Termux 等环境的音频可用性。
依赖方向单向：UI 工具 → desktop_ui emitter → 渲染器；命令工具 → approval/registry/environment helpers；voice_mode 仅依赖底层系统库，不反向依赖 terminal_tool。
