终端工具的执行后端基于 Python asyncio subprocess 管理，`terminal_tool.py`（约 3800 行）支持 local、Docker、Modal、Singularity、Daytona、Vercel Sandbox 六种环境，通过 `TERMINAL_ENV` 环境变量选择。本地执行使用 `subprocess.Popen`，Docker/Modal/Singularity 后端通过各自的 SDK（docker Python SDK、modal-client、Singularity CLI）管理容器生命周期。Cloud sandbox 支持持久化文件系统（跨重建保留工作状态）但不保证长进程存活。后台任务通过 `background=True` 参数启动，支持 VM/container 的自动清理。

桌面 UI 桥接层（`desktop_ui.py`）通过发射器模式（emitter pattern）连接工具层与桌面渲染器。桌面网关在会话启动时通过 `set_emitter()` 安装 `(sid, event, payload)` 事件接收器，工具通过 `emit()` 将事件路由到拥有当前会话的窗口。`SPARKII_UI_SESSION_ID` 环境变量标识当前会话对应的桌面窗口。预览工具（`open_preview_tool.py`）通过 `desktop_ui.emit("preview.open", ...)` 在桌面 GUI 的预览窗格中打开 URL、开发服务器或文件，支持自动 URL 规范化（裸域名加 `https://`、localhost 加 `http://`）。

xterm.js/webview 渲染负责终端与预览窗格的前端展示。终端 fence 协议使用 OSC 序列和 `__SPARKII_FENCE_*__` 标记包装工具输出，防止输出与 shell prompt 混淆。`terminal_hints.py` 提供终端使用提示。`close_terminal_tool.py` 管理终端会话的关闭。可选的 `sounddevice`/`numpy` 依赖支持语音模式下的录音与播放能力。
