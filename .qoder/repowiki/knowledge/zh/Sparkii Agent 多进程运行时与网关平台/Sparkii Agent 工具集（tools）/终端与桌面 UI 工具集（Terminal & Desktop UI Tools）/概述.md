终端与桌面 UI 工具集为 Agent 提供命令执行、进程管理与桌面端交互能力。

终端工具（`terminal_tool.py`，约 3800 行）是 Agent 最核心的执行工具，支持 local、Docker、Modal、Singularity、Daytona、Vercel Sandbox 六种后端环境。通过 `TERMINAL_ENV` 环境变量选择后端。本地执行直接在宿主机运行命令，Docker 后端通过容器隔离执行，Modal/Daytona/Vercel Sandbox 提供云端沙箱。后台任务通过 `background=True` 参数启动，返回 handle 供后续查询。终端会话与 task_id 绑定，支持生命周期管理与自动清理。安全机制包括中断轮询（`is_interrupted()` 在命令执行期间定期检查）、审批回调（`set_approval_callback`）、敏感输出脱敏（`_redact_terminal_error_text`）。Singularity 环境使用自定义 scratch 目录以获得更大存储空间。

桌面 UI 工具（`desktop_ui.py`）提供轻量级桥接层，通过发射器模式将工具事件路由到桌面渲染器。`set_emitter()` 由桌面网关在会话启动时调用，安装 `(sid, event, payload)` 事件接收器；`emit()` 按 `SPARKII_UI_SESSION_ID` 将事件定位到正确的窗口。`available()` 检查是否运行在桌面应用环境中。

预览工具（`open_preview_tool.py`）调用 `desktop_ui.emit("preview.open", ...)` 在桌面 GUI 的预览窗格中打开内容，接受 Web URL、localhost 开发服务器或本地文件路径。输入自动规范化：裸域名添加 `https://`，localhost 添加 `http://`，文件路径直接传递。该工具仅在 desktop_ui 工具集启用时可用，CLI 和网关会话中不可见。`close_terminal_tool.py` 提供终端会话关闭能力，`focus_pane_tool.py` 控制桌面端面板焦点切换。
