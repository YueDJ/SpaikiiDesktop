模块按媒体类型划分为若干独立工具文件，每个文件通过 `tools.registry.registry.register(...)` 将自身声明为可被 agent 调用的 tool：
- 图像生成 (`image_generation_tool.py`)：维护 `FAL_MODELS` 目录（含 FLUX、GPT Image、Ideogram、Recraft、Qwen、Seedream、Krea 等），通过 `_build_fal_payload` / `_build_fal_edit_payload` 把统一输入翻译为各模型专属 payload，并按 `supports` 白名单过滤；请求经 `_submit_fal_request` 走直连 FAL 或 Nous 托管队列网关。
- 视频生成 (`video_generation_tool.py`)：后端无关的 `video_generate` 统一入口，运行时从 `agent.video_gen_registry` 解析已启用插件（xFAL/xAI/Veo 等）并委派到其 `generate`；schema 在 `_build_dynamic_video_schema` 中根据当前 provider 的能力动态拼装。
- BFL/FLUX3 视频 (`flux3_video_tool.py`)：直接对接 Nous 托管网关 REST（`POST /generations` + `GET /generations/<id>`），内置提交→轮询→下载→落盘的完整异步流程，并对本地媒体路径做上传引用替换。
- xAI 视频编辑/扩展 (`xai_video_tools.py`)：仅当 `video_gen.provider == 'xai'` 时可用，调用 `plugins.video_gen.xai` 中的具体实现。
- TTS (`tts_tool.py`, `tts_streaming.py`, `tts_text_normalize.py`, `neutts_synth.py`)：同步路径支持 Edge/ElevenLabs/OpenAI/Mistral/Gemini/xAI/MiniMax/Piper/KittenTTS/NeuTTS 等十多个提供商，通过 `BUILTIN_TTS_PROVIDERS` 与 `tts.providers.<name>: type: command` 两种扩展点；流式路径在 `tts_streaming.py` 中以 `StreamingTTSProvider` ABC + `@register` 装饰器注册 ElevenLabs/OpenAI/Gemini/xAI 四种 PCM 流提供者，统一输出 24kHz mono int16 PCM。
- STT (`transcription_tools.py`)：默认 local faster-whisper，同时支持 Groq/OpenAI/Mistral/xAI/ElevenLabs，并提供 `stt.providers.<name>: type: command` 自定义命令运行器，带超时、进程树终止和输出格式解析。
- 唤醒词 (`wake_word.py`)：openWakeWord/sherpa-onnx/Porcupine 三种本地引擎，共享 16kHz int16 采集与帧级处理接口，支持多 profile 短语注册与自动 tflite 运行时桥接。
- 辅助 (`audio_container.py`, `image_source.py`)：音频容器读写与图片源解析（sandbox 约束、凭证守卫、MIME 探测），被 flux3/video 等工具复用。
依赖方向单向向外：本模块依赖 `tools.tool_backend_helpers`、`tools.managed_tool_gateway`、`tools.image_source`、`tools.registry`、`sparkii_cli.config` 等基础设施，不被其他 tools 反向依赖。
