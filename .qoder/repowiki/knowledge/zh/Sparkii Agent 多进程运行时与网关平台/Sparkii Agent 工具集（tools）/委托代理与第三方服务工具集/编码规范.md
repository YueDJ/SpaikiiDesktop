- 对外部依赖采用延迟 import（如 `jsonschema`、`gateway.status`、`agent.file_safety`），失败时降级为安全默认值而非抛出异常，保证工具可用性。
- 所有敏感数据落盘前经过统一的脱敏函数（`_redact`/`redact_sensitive_text` with `force=True`），确保 live transcript、manifest 与日志不会泄露密钥。
- 配置读取遵循同一模式：优先 `config.yaml` 键，其次环境变量，最后硬编码默认值，并对非法值记录 warning 后回退到安全默认。
- 并发状态通过模块级 `threading.Lock` 保护字典（如 `_active_subagents`、`_records`、`_entries`），并在锁内完成检查-修改-清理的原子操作。
- 第三方客户端以 Provider 抽象暴露：`MicrosoftGraphTokenProvider` 与 `MicrosoftGraphClient` 分离认证与请求逻辑，均提供 `from_env` 工厂方法。
- 异步委派的生命周期通过 SQLite 上的 `delivery_state` 字段（pending/delivered/dropped/unknown）与 claim_id 乐观锁实现跨进程可靠投递与幂等重试。
