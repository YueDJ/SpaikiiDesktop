本模块按职责划分为四个相互独立的子域：
- 委托执行层：`delegate_tool.py` 是核心入口，维护进程级活跃子代理注册表（`_active_subagents`）与暂停开关，负责构建子 agent 系统提示、裁剪工具集（`DELEGATE_BLOCKED_TOOLS`）、并发度与深度限制、心跳停滞检测，并通过 `tools.daemon_pool.DaemonThreadPoolExecutor` 调度；`async_delegation.py` 提供后台委派注册表，使用 SQLite (`state.db` 的 `async_delegations` 表) 持久化任务状态、投递重试与恢复，通过 `process_registry.completion_queue` 将完成事件回灌到 CLI/Gateway 主循环。
- 可观测性层：`delegation_live_log.py` 为每个子任务创建 append-only 日志文件（`cache/delegation/live/<id>/task-*.log`），所有写入经 `_redact` 脱敏，`wrap_progress_callback` 把子 agent 的事件流映射为人类可读行；`delegation_output_schema.py` 在子任务结束时用 jsonschema 校验 JSON 输出并最多发起一次带错误明细的重试轮次。
- 用户交互层：`clarify_tool.py` 定义 OpenAI Function-Calling schema 并调用平台注入的回调；`clarify_gateway.py` 实现跨线程的 clarify 请求队列（`threading.Event` + session-index），供 gateway/adapter 通过 `resolve_gateway_clarify` 唤醒阻塞的 agent 线程。
- 凭据与远端挂载：`credential_files.py` 基于 `ContextVar` 维护会话级凭据文件注册表，结合 `tools.path_security.validate_within_dir` 与 `agent.file_safety.get_read_block_error` 拒绝绝对路径与遍历，向 Docker/Modal/SSH 等远程终端后端生成 bind-mount 或逐文件上传清单。
- 第三方服务客户端：`microsoft_graph_auth.py` 提供 app-only OAuth2 token provider（含缓存与过期倾斜），`microsoft_graph_client.py` 在其上封装分页、重试、401 刷新与大文件流式下载；`openrouter_client.py` 通过 `agent.auxiliary_client.resolve_provider_client` 懒加载共享 AsyncOpenAI 客户端；`xai_http.py` 统一解析 xAI 凭据（OAuth pool → `XAI_API_KEY` → `auth.json`），并提供存储 TTL 配置与 User-Agent 构造。
依赖方向单向：工具层不反向依赖委托层；Microsoft Graph / OpenRouter / xAI 客户端仅被上层工具消费；clarify 与 credential 模块被 delegate_tool 与 terminal 后端共同复用。
