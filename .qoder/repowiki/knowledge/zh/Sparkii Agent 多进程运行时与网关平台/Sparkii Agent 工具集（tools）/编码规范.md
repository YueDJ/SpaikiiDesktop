- 每个工具文件在模块顶层调用 `registry.register(name, toolset, schema, handler, check_fn, ...)` 完成自注册，不在集中列表维护工具清单。
- 工具 handler 统一返回 JSON 字符串（使用 `tool_result()` / `tool_error()`），结构化多模态结果通过 `{"_multimodal": True, "content": [...]}` 信封传递。
- 外部依赖探测通过 `check_fn` 钩子声明，由 registry 统一 TTL 缓存与瞬态失败宽限，避免重复探测外部状态。
- 工具按功能域划分 toolset（如 `browser`、`terminal`、`file`、`mcp-*`、`skills`、`delegation`），并通过 `requires_env` 声明环境变量依赖。
- 可选重型依赖通过 `lazy_deps` 懒加载，仅在首次调用对应工具时才触发安装/导入，降低冷启动成本。
- 插件覆盖内置工具必须显式传入 `override=True`，并由 registry 校验调用者是否属于同一插件命名空间或拥有 operator opt-in。
