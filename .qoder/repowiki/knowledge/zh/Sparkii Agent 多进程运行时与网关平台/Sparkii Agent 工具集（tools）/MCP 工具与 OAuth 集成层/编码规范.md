- 可选依赖（mcp SDK、gateway.platforms.base、sparkii_cli 等）一律通过 try/except ImportError 懒加载并在失败时降级为 no-op 而非抛错，保证模块在无 MCP 安装时仍可导入。
- 对敏感输出统一使用正则脱敏：错误消息经 `_sanitize_error` 替换 `[REDACTED]`，工具描述经 `_scan_mcp_description` 扫描 prompt injection 模式后记录 warning。
- 所有跨进程/跨线程共享的可变状态（`_servers`、`_entries`、`_reserved_sockets`、schema cache）均通过 `threading.Lock` 保护，异步路径内再叠加 `asyncio.Lock` 做细粒度串行化。
- OAuth 流程的交互性控制使用 `contextvars.ContextVar`（`_oauth_interactive_enabled`、`_oauth_interactive_forced`）而非 `threading.local`，确保 `run_coroutine_threadsafe` 调度到 MCP 事件循环线程时仍可见。
- 文件写入遵循原子模式：token 与 schema cache 使用 `os.open(O_EXCL|O_WRONLY)` 写临时文件后 `os.replace` 或 `atomic_json_write`，并以 `0o600` 权限落盘。
- 对外部不可信输入（URI、文件名、URL）进行严格清洗后再用于文件系统或网络请求，例如 `_mcp_resource_filename` 截断控制字符与长度、`is_managed_nous_gateway_url` 用 scheme+netloc 白名单校验而非名称匹配。
