MCP 工具集成层（`tools/mcp_tool.py`）实现 Model Context Protocol 客户端，将外部 MCP 服务器暴露的工具自动注册到 Sparkii 的工具注册表，使 Agent 可像调用内置工具一样调用远程服务。该模块约 7600 行，是工具集中最大的单一文件之一。

传输层支持三种协议。Stdio 模式通过 `subprocess.Popen` 启动 MCP 服务器子进程（如 `npx @modelcontextprotocol/server-filesystem`），通过 stdin/stdout 交换 JSON-RPC 消息，支持空闲超时回收（`idle_timeout_seconds`）和生命周期上限（`max_lifetime_seconds`）。HTTP/Streamable HTTP 模式通过 `httpx` 客户端向远程 URL 发送 POST 请求，支持自定义请求头与身份标识头（`identity_header`，可从配置或当前 Sparkii profile 名称派生）。SSE 模式（`transport: sse`）通过 Server-Sent Events 保持长连接接收服务端推送。

配置从 `config.yaml` 的 `mcp_servers` 节读取。每个服务器条目可声明 `command`/`args`（stdio）或 `url`（HTTP/SSE），以及 `timeout`、`connect_timeout`、`keepalive_interval`、`env`（环境变量过滤）等参数。`supports_parallel_tool_calls` 标记允许同一服务器的工具并发执行。连接失败时自动重连，采用指数退避策略（最多 5 次重试）。

安全机制包括：stdio 子进程的环境变量严格过滤（仅传递安全前缀变量），错误消息中的凭据自动脱敏（`redact_sensitive_text`），以及 HTTP 请求的 credential stripping。OAuth 2.1 授权码流程通过 MCP 的 `authorization` 能力协商实现，支持 PKCE 增强安全。Sampling 支持允许 MCP 服务器通过 `sampling/createMessage` 请求 LLM 补全，可配置模型白名单、最大 token 上限与请求频率限制。
