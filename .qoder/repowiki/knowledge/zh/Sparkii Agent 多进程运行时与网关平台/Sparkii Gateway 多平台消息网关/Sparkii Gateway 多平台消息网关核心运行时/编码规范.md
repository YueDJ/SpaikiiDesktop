- 平台适配器统一继承 `BasePlatformAdapter` 并实现 connect/disconnect/send/get_chat_info 四个抽象方法，平台差异集中在各自子目录（如 `platforms/qqbot/`、`platforms/yuanbao*`）。
- 对重量级平台模块（QQAdapter、YuanbaoAdapter）采用 PEP 562 `__getattr__` 延迟导入，避免每次 CLI 启动都加载 websocket/chunked-upload 栈。
- 用户可见文本在离开网关前统一经过 `_redact_gateway_user_facing_secrets` + `_sanitize_gateway_final_response` 进行敏感信息脱敏与 provider 错误归类，程序化表面（local/api_server/webhook/msgraph_webhook）除外。
- 配置值优先从 `config.yaml` 读取，再通过 `os.environ` 桥接（如 `SPARKII_AUTO_CONTINUE_FRESHNESS`），并提供可解析失败的 fail-closed 默认值。
- 媒体入站一律先经 `validate_inbound_media_size` 校验大小上限，再写入 `get_image_cache_dir()` / `get_audio_cache_dir()` 下的命名临时文件，下载路径还通过 `is_safe_url` + `_ssrf_redirect_guard` 做 SSRF 防护。
- 异步任务与回调普遍包裹 try/except 并在异常时记录日志而非向上抛出，保证单个平台故障不会拖垮整个 gateway 进程（如 `_gateway_loop_exception_handler` 吞掉瞬态网络错误）。
