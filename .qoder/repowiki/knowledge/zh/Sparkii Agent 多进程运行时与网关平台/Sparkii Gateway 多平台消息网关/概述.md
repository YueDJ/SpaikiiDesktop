Sparkii Gateway 是 Sparkii 系统的多平台消息接入层，以 gateway/ 目录为物理载体，负责将异构消息源统一接入 Agent 运行时。该模块的核心是 gateway/run.py（1.3MB），作为主入口编排各平台适配器、会话管理与投递管线，支持 Telegram、WhatsApp、Discord、Signal、Weixin、BlueBubbles、Yuanbao、MsGraph、Feishu、WeCom 等 20+ 消息平台。

网关的关键能力包括：会话管理（session.py + session_context.py）维护用户会话状态、上下文注入与平台能力声明，支持 PII 脱敏与多租户隔离；投递管线（delivery.py + delivery_ledger.py）负责消息路由、格式转换与投递确认；流式输出系统（stream_consumer.py + stream_dispatch.py）支持实时流式传输，根据平台特性选择草稿流、编辑流或关闭模式；平台注册表（platform_registry.py）统一管理平台适配器的生命周期与配置。

网关与 Agent 运行时紧密协作：通过 SessionContext 向 Agent 注入会话来源、平台能力、Home Channel 等上下文信息，使 Agent 知道在哪里、能做什么、如何投递；通过 GatewayStreamConsumer 实时转发 Agent 的流式输出到目标平台；通过 slash_commands.py 提供平台特定的斜杠命令支持。配置系统（config.py）提供细粒度的平台配置、流式输出参数、会话重置策略与并发会话上限。

该模块采用适配器模式，每个平台通过 BasePlatformAdapter 抽象基类实现统一接口，屏蔽平台差异。支持会话隔离、速率限制、媒体缓存、健康检查、重连与恢复等生产级特性。与 TUI Gateway（tui_gateway/）共享传输层抽象，支持 WebSocket 与 Stdio 两种通信模式。整体架构确保系统在高并发多平台场景下的稳定与可扩展性。
