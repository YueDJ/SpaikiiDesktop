文档站点的技术栈围绕 Docusaurus 3 + React + TypeScript 构建，充分利用静态站点生成（SSG）与客户端水合（Hydration）的混合渲染模式。

**核心框架**：Docusaurus 3.10.2 使用 Classic Preset 构建，配置文件 `docusaurus.config.ts` 采用 TypeScript 编写，提供类型安全的配置体验。`routeBasePath: '/'` 将文档设置为站点根路径，`blog: false` 禁用博客功能以聚焦技术文档。`sidebarPath: './sidebars.ts'` 定义侧边栏导航结构，支持自动折叠与可隐藏配置。

**主题与插件**：`@docusaurus/theme-mermaid` 提供 Mermaid 图表渲染能力，文档中可直接编写 Mermaid 语法。`@docusaurus/plugin-client-redirects` 处理静态重定向映射，通过 `redirects` 数组声明 from/to 路径对。Prism 语法高亮使用 `prism-react-renderer` 的 GitHub 与 Dracula 双主题（亮/暗模式）。

**搜索集成**：Algolia DocSearch 配置于 `themeConfig.algolia`，使用公共 Search-Only API Key（安全可提交），`contextualSearch: true` 按当前语言作用域过滤结果。索引由 Algolia Crawler 在 `crawler.algolia.com` 配置并自动填充。

**国际化**：`i18n` 配置声明 `defaultLocale: 'en'` 与 `locales: ['en', 'zh-Hans']`，`localeConfigs` 为每种语言设置显示标签与 HTML lang 属性。翻译文件存储在 `i18n/zh-Hans/` 目录下，遵循 Docusaurus 的 `docusaurus-plugin-content-docs/current/` 目录结构。

**构建工具链**：TypeScript 6 提供类型检查，React 19 用于自定义组件开发（`src/` 目录），`@tsconfig/docusaurus` 提供 Docusaurus 专用的 TypeScript 配置预设。静态资源存放于 `static/` 目录，CSS 自定义样式位于 `src/css/custom.css`。
