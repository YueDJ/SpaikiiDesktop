- 入口文件负责生命周期与资源清理：`web/src/main.tsx` 按固定顺序包裹 Provider，`ui-tui/src/entry.tsx` 集中处理 TTY 检测、终端模式重置、信号监听、内存监控与优雅退出。
- 路由与页面采用懒加载：`web/src/App.tsx` 中所有页面通过 `lazy(() => import(...))` 引入，减少首屏 bundle 体积。
- 插件化扩展：Web 端通过 `plugins/registry`、`slots.ts`、`PluginPage` 暴露插槽机制，允许外部脚本注册组件并覆盖/插入路由；TUI 端通过 `sdk/` 暴露宿主 API 给外部应用。
- 测试文件与源码同目录并以 `.test.ts(x)` 命名，统一通过 Vitest 运行（`vitest.config.ts`）。
- 状态管理在 Web 端使用 React Context（`contexts/` 下 `ProfileProvider`、`SystemActions`、`PageHeader` 等），在 TUI 端使用 Nanostores（`src/app/uiStore.ts` 等）并通过 `@nanostores/react` 订阅。
- 国际化文案按语言拆分为独立文件（`web/src/i18n/*.ts`），通过 `define-locale.ts` 聚合并由 `I18nProvider` 提供。
