- RPC 方法通过 `method_ctx.HandlerRegistry` 的 `@method("<namespace>.<name>")` 装饰器声明，并按功能拆入 `methods_*.py` 文件集中注册。
- 所有 I/O 输出走 `transport.Transport` 抽象并通过 `current_transport()` 获取，禁止直接操作 `sys.stdout`，以便 stdio 与 WebSocket 共用同一套 handler。
- 长耗时或网络阻塞的 RPC 方法显式加入 `server._LONG_HANDLERS` 集合，交由 `ThreadPoolExecutor` 异步执行，保持 stdin 读取循环响应。
- 会话状态集中保存在模块级 `_sessions` dict 中，并通过 `_sessions_lock`（RLock）保护，关键路径先 `_pop_session_by_id` 原子摘除再执行慢速 finalize，避免并发竞态。
- 异常与退出统一落盘：`sys.excepthook` 与 `threading.excepthook` 追加到 `_CRASH_LOG`，信号处理与 `_log_exit` 记录退出原因，保证 TUI 可诊断 gateway 崩溃。
- 子进程（如 `_SlashWorker`）使用 `start_new_session=True` 创建独立进程组，并以 UTF-8 + `errors='replace'` 解码 stderr/stdout，防止编码错误导致网关崩溃。
