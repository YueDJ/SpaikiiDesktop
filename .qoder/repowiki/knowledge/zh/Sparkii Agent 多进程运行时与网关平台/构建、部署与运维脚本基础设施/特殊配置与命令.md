`scripts/install.sh` 支持 `--manifest` 打印桌面引导阶段清单、`--stage <NAME>` 单步执行、`--json` 输出 JSON 结果帧；`scripts/release.py` 通过 CalVer 标签生成 changelog 并发布 GitHub Release（`--bump minor --publish [--first-release] [--date YYYY.M.D]`）；`nix/devShell.nix` 通过 `mkNpmDevShellHook` 批量处理多 workspace 的 `package.json`，并在 shellHook 中设置 `SPARKII_PYTHON_SRC_ROOT`、`VIRTUAL_ENV` 与 `playwright-test` 路径以复用 Nix 提供的 Node/Playwright。
