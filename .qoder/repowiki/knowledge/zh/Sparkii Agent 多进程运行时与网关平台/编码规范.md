- 所有 Python 入口在首行导入 `sparkii_bootstrap` 以修复 Windows UTF-8 stdio，缺失时静默降级。
- 配置统一经 `load_cli_config` 合并用户/项目 YAML 并桥接为 `TERMINAL_*`、`AUXILIARY_*`、`SPARKII_*` 等环境变量，各子模块只读 env 而不直接解析 YAML。
- 会话与消息持久化统一通过 `sparkii_state.SessionDB` 访问 `state.db`，禁止子模块自行维护会话索引文件。
- 可选/重型依赖（provider、搜索、TTS、语音、记忆等）一律放入 `pyproject.toml` 的 optional-dependencies 并由 `tools/lazy_deps.py` 在首次使用时懒安装，不进入核心 dependencies。
- 日志统一由 `sparkii_logging.setup_logging` 初始化到 `~/.sparkii/logs/`，入口层捕获异常避免启动失败。
- 顶层单文件模块（run_agent、model_tools、mcp_serve、cli 等）通过 `pyproject.toml` 的 `py-modules` 显式声明以便被 setuptools/uv2nix 打包进 sealed venv。
