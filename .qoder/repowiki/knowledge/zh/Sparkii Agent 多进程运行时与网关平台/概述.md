以 CLI/TUI/Gateway/ACP/MCP 为统一入口，编排 AIAgent 运行时、工具集、插件与消息平台，将异构会话持久化到共享 SQLite 状态库。该平台层是 Sparkii 系统的顶层编排框架，整合了四大核心子系统：CLI 主程序包（sparkii_cli/）提供命令行入口与交互式体验，Sparkii Agent 运行时（agent/）负责 AI 代理的对话循环与工具执行，Sparkii Gateway（gateway/）实现多平台消息接入与会话管理，ACP 适配器（acp_adapter/）支持标准化的 Agent 通信协议。

平台的核心架构采用多进程设计，Gateway 与 Agent 运行在独立进程中，通过事件驱动的消息流进行通信。会话状态统一持久化到 SQLite 数据库（state.db），支持跨进程、跨平台的会话恢复与分支。工具系统（tools/）通过声明式注册机制集中管理 100+ 工具能力，涵盖文件操作、代码执行、浏览器自动化、媒体生成、MCP 集成等领域。

平台支持丰富的接入方式：通过 CLI 直接交互，通过 TUI 获得终端富文本体验，通过 Gateway 接入 Telegram/WhatsApp/Discord/Signal/Weixin 等 20+ 消息平台，通过 ACP 协议实现标准化的 Agent 间通信，通过 MCP 协议集成外部工具服务。配置系统采用分层设计，支持用户级、项目级、环境变量三级配置的智能合并与安全迁移。插件机制允许第三方扩展 CLI 命令、生命周期钩子与工具能力，确保系统的长期可扩展性。
