技术栈以 Python 标准库为主体，辅以少量可选依赖以增强调度表达力。核心组件包括：

**调度引擎**：基于 `croniter` 库解析 5/6 字段 cron 表达式，支持标准 Unix cron 语法与秒级精度扩展。调度循环使用 `threading.Event` 驱动 60 秒间隔的阻塞等待，`concurrent.futures.ThreadPoolExecutor` 实现并行任务执行。`asyncio` 事件循环桥接异步 Agent 调用与同步调度线程。

**持久化存储**：任务定义存储于 `jobs.json`（原子写入 + 文件锁），执行审计记录写入 SQLite `executions.db`（WAL 模式 + `PRAGMA synchronous=FULL`），任务记事本使用独立的 SQLite `notepad.db`。建议系统使用 `suggestions.json` 存储。所有文件均位于 `~/.sparkii/cron/` 目录下，权限设为 0600。

**跨进程同步**：Unix 系统使用 `fcntl.flock()` 实现跨进程文件锁，Windows 系统降级为 `msvcrt.locking()`。进程级使用 `threading.RLock` 保护内存中的临界区。文件锁超时设为 30 秒，防止僵死进程无限阻塞调度器心跳。

**变更检测**：`hashlib.sha256` 计算 monitor 输出的精确字节哈希，`difflib.unified_diff` 生成变更上下文块注入 prompt。HTTP URL 监控使用 `urllib.request` 发起带超时的 GET 请求（30 秒超时，256 KiB 上限）。

**安全守卫**：`re` 模块编译的正则表达式匹配网关生命周期命令，`shlex` 分词器解析 shell 命令以区分数据管道与真实执行。二进制文件通过魔数检测（ELF/PE/Mach-O）跳过，防止编译产物被误解析。
