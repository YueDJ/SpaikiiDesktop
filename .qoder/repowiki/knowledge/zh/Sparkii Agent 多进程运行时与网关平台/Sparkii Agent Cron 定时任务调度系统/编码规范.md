- 所有持久化写入采用原子替换模式（临时文件 + atomic_replace/fsync），避免并发读者看到撕裂数据。
- 跨进程临界区统一通过 `_jobs_lock()` 上下文管理器包裹 load→modify→save 三段式操作，并在 fcntl/msvcrt 不可用时降级为仅进程内 RLock。
- 路径与 job id 在进入文件系统前进行严格校验（拒绝 `..`、绝对路径、分隔符），防止输出目录逃逸。
- 模块级常量（如 `SPARKII_DIR`、`CRON_DIR`）通过 `_current_cron_store()` 动态解析当前 profile 的 `get_sparkii_home()`，并通过 `ContextVar` 覆盖支持测试隔离。
- 重型或可选依赖（`croniter`、`sparkii_cli.tools_config`、`gateway.*`）一律延迟 import，仅在首次使用时加载以避免启动开销与循环导入。
- 错误处理遵循 best-effort 原则：心跳、审计日志、mirror 投递等辅助写失败被吞掉，绝不让其中断 tick 主循环。
