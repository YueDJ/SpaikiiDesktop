- 子命令通过 `subcommands/<group>.py` 暴露 `build_<group>_parser(subparsers, ...)` 工厂函数，由 `main.py` 统一组装，处理器保留在 `main.py` 中以避免循环导入。
- 启动路径遵循“零依赖预热 → 配置文件 → 日志 → 业务模块”的严格顺序，关键决策（TTY、IPv4、redact_secrets、profile）在任意第三方 import 之前完成。
- Dashboard 相关能力（认证、中间件、路由）集中在 `dashboard_auth/`，外部入口通过该包的 `registry`/`routes` 注册而非直接耦合。
- 可观测性指标通过 `observability/shared_metrics_contract.py` 定义的 JSON Schema 发布，订阅方使用同一 schema 校验消息结构。
- 平台差异（Windows/POSIX、Termux、容器）通过 `_startup_fast`、`platforms.py`、`_scan_venv_blockers.py` 等薄封装处理，调用方不感知具体分支。
