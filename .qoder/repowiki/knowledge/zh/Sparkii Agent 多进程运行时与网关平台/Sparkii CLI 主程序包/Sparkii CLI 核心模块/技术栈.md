Sparkii CLI 核心模块是 CLI 主程序包的基础设施层，包含命令注册、配置解析、认证管理、模型切换、插件系统、会话持久化与 Web 路由等支撑所有子命令运行的关键组件。

**命令注册表**：`commands.py` 定义 `CommandDef` 数据类与全局 `COMMAND_REGISTRY` 列表，每个斜杠命令（`/new`、`/model`、`/cron`、`/goal` 等）注册为一个 `CommandDef` 实例，携带名称、描述、分类、别名、参数提示、子命令列表、平台可见性（`cli_only`/`gateway_only`）、忙碌策略（`busy_policy`：`dispatch`/`reject`/`interrupt_then_dispatch`）等元数据。该注册表是 CLI 帮助、Gateway 调度、Telegram BotCommands、Slack 子命令映射与自动补全的唯一数据源。

**配置管理**：`config.py` 实现分层配置加载——`config.yaml`（用户设置）→ `.env`（密钥）→ 环境变量，通过 `cfg_get()` 函数按点分路径读取配置值。支持配置迁移（`config_migrations.py`）在版本升级时自动调整配置结构，损坏配置自动备份（`_backup_corrupt_config()`）。`fallback_config.py` 实现提供商降级链配置。

**认证与凭据**：`auth.py` 管理多提供商凭据池，`credential_lifecycle.py` 处理凭据的创建、轮换与耗尽状态，`nous_auth_keepalive.py` 维护 Nous 账户的认证心跳。支持 OpenAI、Anthropic、Google、Azure、AWS Bedrock 等多提供商的 API Key 与 OAuth 令牌管理。

**会话持久化**：`sqlite_runtime.py` 提供 SQLite 运行时，管理会话数据库的连接、WAL 模式配置与安全读取（`sqlite_safe_read.py`）。会话支持跨进程恢复、分支与导出（HTML/Markdown 格式）。`active_sessions.py` 追踪活跃会话列表。

**Web 路由**：`web_server.py`（基于 FastAPI/Starlette）提供 REST API 与 WebSocket 端点，`web_routers/` 子目录定义各功能域的路由。Dashboard 通过这些路由实现浏览器端的会话管理、配置编辑与实时对话。
