插件系统、技能中心与工具配置模块实现 Sparkii 的三大可扩展性子系统：插件发现与注册、Skills Hub 技能管理、以及按平台/工具集的交互式工具配置向导。

plugins.py（2732 行）是 Sparkii 插件系统的核心实现。插件从四个来源扫描加载：bundled 插件（随仓库分发的 plugins/ 目录，排除 memory/ 和 context_engine/ 子目录，它们有独立发现路径）、用户插件（~/.sparkii/plugins/）、项目插件（.sparkii/plugins/，需通过 SPARKII_ENABLE_PROJECT_PLUGINS 环境变量启用）、以及 pip 插件（暴露 sparkii_agent.plugins entry-point 组的包）。后发现的源在同名冲突时覆盖前者。每个目录插件必须包含 plugin.yaml 清单和 __init__.py 中的 egister(ctx) 函数。PluginContext 暴露 egister_tool()、egister_*_provider()、egister_platform()、egister_cli_command()、inject_message() 等扩展点，所有 provider 注册均做类型校验，覆盖内置工具需显式 llow_tool_override 配置授权。模块支持 SPARKII_PLUGINS_DEBUG=1 环境变量开启详细的插件发现调试日志。

plugins_cmd.py（2171 行）实现 sparkii plugins CLI 子命令，支持从 Git 仓库安装、更新、删除和列出插件。安装流程支持完整 URL 和 owner/repo GitHub 简写，通过 _sanitize_plugin_name() 防止路径遍历攻击。安装后如插件附带 fter-install.md 则用 Rich Markdown 渲染提示。

	ools_config.py（5472 行）维护统一的工具配置 UI 与持久化，集中声明 CONFIGURABLE_TOOLSETS、TOOL_CATEGORIES（含各 provider 的环境变量、post_setup 钩子、Nous 订阅集成），默认关闭集合 _DEFAULT_OFF_TOOLSETS，并通过 _get_effective_configurable_toolsets() 动态合并插件提供的 toolset。skills_config.py（203 行）提供技能的全局/按平台禁用列表管理，通过 sparkii skills 命令进入交互式配置。
