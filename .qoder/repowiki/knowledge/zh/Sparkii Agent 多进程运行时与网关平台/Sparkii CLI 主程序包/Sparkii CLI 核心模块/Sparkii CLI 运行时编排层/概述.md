运行时编排层是 Sparkii Agent 的进程入口与启动编排中心，将配置加载、认证凭据、模型提供商、插件技能、子命令与 Web/代理运行时串联为统一的 sparkii CLI。该层位于 sparkii_cli/ 顶层模块中，以 main.py 为核心调度枢纽。

认证编排：启动时从凭据池（credential_lifecycle.py）加载可用凭据，nous_auth_keepalive.py 维护 Nous 账户的长连接心跳。auth_commands.py 提供 sparkii auth add/list/remove/reset 子命令。memory_oauth.py 处理 OAuth 令牌的刷新与持久化。

启动流程：进程启动时依次执行——sparkii_bootstrap 设置 Windows UTF-8 stdio、_subprocess_compat.suppress_platform_ver_console() 抑制控制台闪烁、_startup_fast 快速路径引导、_early_recovery.recover_if_needed() venv 自修复、_parser.build_top_level_parser() 构建 argparse 解析器、_apply_profile_override() 处理 --profile 参数、配置加载与日志初始化、子命令分发。

配置编排：config.py 的 load_config() 加载并合并分层配置（config.yaml + .env + 环境变量），config_migrations.py 在加载后检查并执行必要的配置迁移。fallback_config.py 构建提供商降级链，当主模型不可用时自动切换到备选提供商。env_loader.py 处理 .env 文件的加载与变量展开。

运行时服务编排：gateway.py 编排 Gateway 服务的安装/启动/停止/状态查询，web_server.py 启动 Web Dashboard，pty_bridge.py 提供交互式终端命令的 PTY 桥接。所有运行时服务共享同一配置上下文与凭据池。

模型与插件编排：model_switch.py 处理运行时模型切换，model_catalog.py 维护可用模型目录，agent_plugins.py 管理 Agent 插件的加载与生命周期。skills_hub.py 提供 Skills Hub CLI 入口，plugins.py/plugins_cmd.py 管理第三方插件。
