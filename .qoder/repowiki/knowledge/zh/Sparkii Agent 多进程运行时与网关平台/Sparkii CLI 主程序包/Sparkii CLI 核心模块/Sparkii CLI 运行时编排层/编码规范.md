- 所有子命令通过 `subcommands/<cmd>/build_<cmd>_parser` 工厂函数注册到顶层 argparse，避免在模块级直接构造 parser。
- 对可能失败的外部依赖（logging、setproctitle、YAML、第三方 SDK）采用 try/except best-effort 包裹，确保 CLI 启动不因单点故障崩溃。
- 启动期关键决策（TUI/CLI、IPv4 强制、redact_secrets、profile）在 import 重模块之前通过 `_startup_fast`、`read_raw_config`、`_apply_profile_override` 等轻量路径完成。
- 跨子模块共享的状态（如 `PROVIDER_REGISTRY`、`get_sparkii_home`、`load_config`）集中放在 `config`、`auth`、`platform_runtime_helpers` 等顶层模块，子模块通过导入而非参数传递获取。
- 平台差异通过 `platforms`、`_subprocess_compat`、`win_pty_bridge` 等 shim 封装，子命令不直接调用 platform-specific API。
