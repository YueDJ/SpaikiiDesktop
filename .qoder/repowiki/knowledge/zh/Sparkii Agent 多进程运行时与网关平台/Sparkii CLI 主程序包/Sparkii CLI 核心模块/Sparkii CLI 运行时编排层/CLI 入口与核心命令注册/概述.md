CLI 入口与核心命令注册是 sparkii 命令行工具的进程起点与命令分发核心，由 main.py、_parser.py 和 commands.py 三个模块协作完成。

进程入口（main.py）：作为 sparkii 命令的顶层入口（约 12,700 行），main() 函数协调完整的启动序列——UTF-8 stdio 引导、venv 自修复、--profile 参数提取、配置加载、日志初始化后，调用 build_top_level_parser() 构建 argparse 解析器，注册所有子命令，最终通过 args.func(args) 分发到对应的 cmd_* 处理函数。默认无子命令时进入交互式聊天模式。

命令注册表（commands.py）：COMMAND_REGISTRY 是全局唯一的斜杠命令定义列表，每个 CommandDef 实例携带完整元数据：名称、描述、分类、别名、参数提示、子命令列表、平台可见性、忙碌策略与执行器键。resolve_command() 函数按名称或别名查找命令定义，SlashCommandCompleter 和 SlashCommandAutoSuggest（依赖 prompt_toolkit）为 REPL 提供 Tab 补全与自动建议。gateway_help_lines() 为 Gateway 消息平台生成命令帮助文本。注册表同时被 Telegram BotCommands 注册、Slack 子命令映射、Web Dashboard 命令面板等多个消费者引用。

解析器构建（_parser.py）：build_top_level_parser() 返回 (parser, subparsers, chat_parser) 三元组。顶层 parser 定义全局标志（-q 单次查询、-c 恢复会话、--tui/--cli 模式选择、-s toolset 选择、-w 工作树隔离等），chat_parser 处理聊天子命令的专属参数。_inherited_flag() 装饰器标记需要在 CLI 重新启动时继承的标志（如 --profile），供 relaunch.py 的重启动表构建器内省发现。
