- 对外部重型依赖（如 `tools.skills_hub`、`agent.*`、`yaml`）采用函数内延迟 import，避免启动时循环依赖与冷启动开销。
- 插件扩展点统一通过 `PluginContext.register_*` 方法暴露，并在内部先做 `isinstance` 类型检查再写入对应 registry，失败时记录 WARNING 而非抛出异常。
- 对可能覆盖内置能力的操作（工具覆盖、LLM 代理、provider 替换）强制要求 `config.yaml` 中 `plugins.entries.<id>.allow_tool_override: true` 显式授权，未授权则拒绝或静默忽略。
- CLI 命令与 slash command 共用同一组 `do_*` 纯函数，入口层只做参数解析与 Rich 渲染，便于在 CLI、TUI、gateway 多表面复用。
- Skill 安装严格遵循 quarantine → security scan → policy check → install 的安全流水线，任何阶段失败都会清理临时目录并写入审计日志。
- 工具集配置以声明式字典（`CONFIGURABLE_TOOLSETS`、`TOOL_CATEGORIES`）驱动 UI 与校验，新增 provider 只需追加条目而无需改动渲染逻辑。
