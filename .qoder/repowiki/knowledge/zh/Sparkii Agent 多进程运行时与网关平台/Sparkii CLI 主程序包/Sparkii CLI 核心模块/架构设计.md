本模块以 `main.py` 为进程入口，通过 `_parser.py` 解析 CLI 参数并路由到 `subcommands/` 下的各子命令；启动阶段由 `lifecycle.py`、`config.py`、`auth.py`、`plugins.py`、`models.py` 等顶层模块按顺序完成环境探测、配置加载、凭据注入、提供商注册与插件发现，随后将控制权交给具体子命令或 Web/代理服务器（如 `gateway.py`、`proxy/server.py`、`web_server.py`）。子模块之间通过共享的 `config`、`providers`、`profiles`、`plugins`、`sessions` 等单例式状态对象进行通信，避免直接耦合；`dashboard_auth/` 提供统一的 Web 鉴权中间件供 dashboard 相关路由复用，`observability/` 暴露共享指标契约供各子命令上报遥测，`proxy/` 与 `web_routers/` 则作为独立 HTTP 服务被主进程按需拉起。
