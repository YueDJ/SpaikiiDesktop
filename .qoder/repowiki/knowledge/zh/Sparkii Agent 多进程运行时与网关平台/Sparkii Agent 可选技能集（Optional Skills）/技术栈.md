可选技能集的技术栈以轻量级、零编译为设计原则，确保技能可在任何支持 Python 3.11+ 的环境中运行。

**技能定义格式**：采用 `SKILL.md` 声明式 Markdown 格式，使用 YAML front matter 声明元数据（名称、版本、作者、标签），Markdown body 描述技能能力与使用说明。支持 `blueprint:` 块声明 Cron 自动化提案的 job_spec 参数。SKILL.md 由 Skills Hub CLI 解析并索引。

**脚本运行时**：以 Python 脚本为主（约 90%），辅以 Shell/JS 工具。Python 脚本大量使用标准库（`urllib.request` 发起 HTTP 请求、`json` 解析响应、`argparse` 处理命令行参数），部分脚本依赖第三方库如 `openai`（OpenAI API 调用）、`anthropic`（Anthropic API 调用）。脚本设计为独立可执行，支持 `python3 ~/.sparkii/skills/<domain>/<skill>/scripts/*.py` 直接调用。

**外部 API 集成**：技能依赖多种外部服务：CoinGecko（加密货币价格）、OpenRouter（多模型 LLM 路由）、EVM RPC（区块链交互）、Polymarket（预测市场）、Stripe（支付处理）、ENS（以太坊域名）、4byte.directory（函数选择器解析）。API Key 通过环境变量或 `.env` 文件注入。

**存储与分发**：技能文件存储在 GitHub 仓库（`optional-skills/` 目录）中，按领域分类（21 个子目录）。Skills Hub CLI 使用 GitHub API 获取技能列表与内容，支持增量更新。安装时将技能文件复制到 `~/.sparkii/skills/<domain>/<skill>/`，保留目录结构以便脚本相对路径引用。

**安全机制**：安装前检查技能来源的信任级别，`community` 级别技能需用户显式确认。脚本执行前由 `tools/skills_guard.py` 进行静态分析，检测潜在的安全风险（文件系统越界访问、网络请求等）。
