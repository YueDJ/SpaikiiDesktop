可选技能集（Optional Skills）是由 Nous Research 维护的官方 Sparkii Agent 技能集合，包含 21 个领域分类下的数十个技能模块，涵盖金融（finance）、区块链（blockchain）、通信（communication）、创意（creative）、数据科学（data-science）、DevOps、邮件（email）、游戏（gaming）、健康（health）、安全（security）、软件开发（software-development）、Web 开发（web-development）等领域。这些技能默认不激活，用户通过 Skills Hub 按需安装到 `~/.sparkii/skills/` 目录。

每个技能以 `SKILL.md` 文件为核心声明，采用结构化的 Markdown 格式定义技能的触发条件、能力描述、参数格式与执行脚本。SKILL.md 支持声明 `blueprint:` 块，安装时会向 Cron 建议系统注册自动化提案而非直接创建定时任务。技能的可执行脚本位于 `scripts/` 子目录，以 Python 或 Shell 脚本为主，运行时通过标准库（`urllib`、`json`、`argparse`）或第三方库（`openai`、`anthropic`）调用外部 API（CoinGecko、OpenRouter、EVM RPC、Polymarket、Stripe 等）和公开服务（ENS、4byte.directory）。

技能管理通过 `sparkii skills` 子命令实现：`browse` 浏览官方/社区/GitHub 来源的技能目录，`install` 按标识符安装技能及其依赖，`update` 更新已安装技能到最新版本，`remove` 卸载技能，`search` 在所有来源中搜索技能。安装后的技能被 Agent 运行时自动发现，在对话中根据用户意图匹配并调用。

技能系统支持三级信任模型：`builtin`（内置）、`trusted`（官方）、`community`（社区），不同信任级别的技能在安装、执行时有不同的安全策略。GitHub 来源的技能通过 Tap 机制集成，支持 NVIDIA、OpenAI 等提供商的官方 Tap 仓库。
