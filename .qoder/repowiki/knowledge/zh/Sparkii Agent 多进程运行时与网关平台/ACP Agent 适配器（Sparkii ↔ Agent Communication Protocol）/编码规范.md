- 对外部可选依赖（`acp`、`sparkii_cli.*`、`run_agent`、`agent.*`）一律采用函数内延迟 import，避免模块级导入失败导致整个适配器不可用。
- 所有 ACP 异步更新通过 `safe_schedule_threadsafe` 从 AIAgent 工作线程安全投递到主事件循环，禁止直接 await。
- 工具结果格式化遵循“专用 formatter + 通用 fallback”模式：`_build_polished_completion_content` 根据工具名分派到 `_format_*` 函数，未知工具走 `_format_generic_structured_result`。
- Windows/WSL 路径在边界处统一通过 `translate_cwd_for_wsl_backend` / `windows_path_to_wsl` 转换，确保编辑器 cwd 与进程 cwd 一致。
- 资源读取统一受 `_MAX_ACP_RESOURCE_BYTES` 限制，并以 data URL 或截断文本形式返回，避免超大附件阻塞协议。
- 日志全部写入 stderr，stdout 严格保留给 ACP JSON-RPC；通过 `RedactingFormatter` 与自定义 `Filter` 过滤探针方法的 -32601 噪音。
