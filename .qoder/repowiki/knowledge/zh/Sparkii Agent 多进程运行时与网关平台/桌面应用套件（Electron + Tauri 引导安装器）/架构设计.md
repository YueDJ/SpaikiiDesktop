本模块由三个子包组成，构成完整的桌面产品形态：
- `apps/desktop`：基于 Electron 40 的主应用，采用 Vite 构建 React/TypeScript 渲染进程（`src/main.tsx` 入口），并通过 `electron/main.ts`、`electron/preload.ts` 暴露 IPC 桥接；后端通过 `electron/backend-child.ts` 以子进程方式启动并管理生命周期（健康检查、探针、连接状态等）。应用内按功能划分 `app/`（路由、会话、设置、shell、插件等）、`components/`（UI 组件、onboarding、assistant-ui）、`store/`（nanostores 状态）、`lib/`（工具与协议封装）、`plugins/`（kanban 等扩展）和 `e2e/`（Playwright 端到端测试）。
- `apps/bootstrap-installer`：独立的 Tauri 2 应用（`src-tauri/` 含 Rust 后端 `bootstrap.rs`、`install_script.rs`、`update.rs` 等），前端使用 Vite + React 提供带进度条的安装向导 UI，通过 `@tauri-apps/plugin-shell` 调用系统脚本完成首次安装。
- `apps/shared`：纯 TypeScript 共享库（`@sparkii/shared`），通过 `package.json` 的 `exports` 字段导出 billing、skin、websocket-url 等类型与工具，被 desktop 与 bootstrap-installer 共同引用。
依赖方向：desktop 与 bootstrap-installer 均依赖 shared；desktop 通过 electron-builder 打包为 dmg/nsis/AppImage，bootstrap-installer 通过 tauri build 打包原生安装包，两者互不耦合。
