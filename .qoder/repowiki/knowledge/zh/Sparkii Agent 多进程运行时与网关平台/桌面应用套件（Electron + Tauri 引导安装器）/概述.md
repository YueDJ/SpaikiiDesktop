桌面应用套件由 pps/desktop（Electron + React 桌面应用）和 pps/bootstrap-installer（Tauri 引导安装器）两个子项目组成，为 Sparkii 提供原生桌面体验和零依赖首次安装能力。

pps/desktop 是跨平台桌面应用（macOS、Windows、Linux），采用 Electron 主进程 + React 渲染进程架构。Electron 主进程（electron/main.ts）负责后端解析与验证（按优先级链：SPARKII_DESKTOP_SPARKII_ROOT → 源码检出 → 已安装的 managed install → PATH 上的 sparkii → 系统 Python → 首次引导安装器）、原生文件系统/Git/窗口能力暴露、以及 preload 桥接。React 渲染进程（src/）拥有 Desktop 路由、面板、交互状态和 @assistant-ui/react 转录组件，共享原子状态在 src/store 中，传输/原生适配器在 src/lib 中。后端通过 pps/shared 包连接 TUI Gateway 的 JSON-RPC/WebSocket API，复用与浏览器 Dashboard 相同的通信层。

应用支持三种连接模式：managed local backend（本地管理的 sparkii serve 进程）、explicit remote gateway（远程 Gateway）和 Sparkii Cloud 连接。首次运行时如无可用运行时，提供"连接到现有 Sparkii"选项，探测 Gateway 认证方式（Token 或 OAuth），测试 HTTP 和 WebSocket 连通性后保存加密配置。项目抽象支持多文件夹/仓库/工作树/会话管理。Profile 切换和连接模式变更通过软工作区切换实现，不触发冷启动。

pps/bootstrap-installer 是基于 Tauri（Rust）的引导安装器，负责在无 Python 环境的机器上完成 Sparkii 的首次安装。uild.rs（191 行）在编译时将 install.ps1 的 commit/branch pin 烘焙到二进制中（通过 SPARKII_BUILD_PIN_COMMIT 和 SPARKII_BUILD_PIN_BRANCH 环境变量），支持不可变 commit pin（用于发布）和分支跟踪（开发默认）。前端使用 React + Vite，包含 welcome、progress、success、failure 四个路由页面和全局状态管理（store.ts，484 行）。Tauri capabilities 配置控制原生 API 访问权限。
