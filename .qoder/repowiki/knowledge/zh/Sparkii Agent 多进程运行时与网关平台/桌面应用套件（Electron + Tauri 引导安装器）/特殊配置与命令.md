桌面应用开发需先运行 `npm run dev:renderer` 启动 Vite 服务，再运行 `npm run dev:electron` 编译 electron 侧代码并通过 `scripts/bundle-electron-main.mjs` 注入后启动 Electron；生产构建走 `npm run build && npm run builder`，macOS 产物经 `scripts/notarize.mjs` 签名；引导安装器通过 `npm run tauri:dev` / `tauri:build` 开发或构建；E2E 在 headless 环境下通过 `WLR_BACKENDS=headless WLR_NO_HARDWARE_CURSORS=1 cage -- npx playwright test e2e/` 执行视觉回归。
