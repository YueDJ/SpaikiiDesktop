- 每个技能目录必须包含 SKILL.md，并在 YAML frontmatter 中声明 name、description、version、author、license、platforms 及 hermes.metadata（tags/category/related_skills/requires_toolsets）。
- 可执行代码统一放在技能目录下的 scripts/ 子目录，SKILL.md 通过绝对路径 `~/.hermes/skills/<domain>/<skill>/scripts/<file>.py` 引用。
- 参考文档、提示词模板、样式预设等静态资源集中放在 references/、templates/、prompts/ 子目录，便于 SKILL.md 交叉引用。
- SKILL.md 采用固定章节结构：When to Use → Prerequisites → Quick Reference → Procedure（分步骤编号）→ Pitfalls → Verification，保证技能使用说明的一致性。
- 需要额外依赖的技能在目录内提供 requirements.txt 或 setup.sh，并在 Prerequisites 中明确列出环境要求（如 Python 版本、API Key、环境变量）。
