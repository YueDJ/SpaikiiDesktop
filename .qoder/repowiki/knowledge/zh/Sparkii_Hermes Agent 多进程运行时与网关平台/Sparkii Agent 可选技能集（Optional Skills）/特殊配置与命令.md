可选技能的管理与配置通过 `sparkii skills` 子命令与配置文件协同完成。

**核心子命令**：
- `sparkii skills list`：列出已安装技能，显示名称、来源、信任级别与版本。
- `sparkii skills browse [--source official|community|github]`：浏览可用技能目录，支持按来源过滤。GitHub 来源显示 Tap 提供商标签。
- `sparkii skills install <identifier>`：按标识符安装技能，自动创建目录结构并下载 SKILL.md 与脚本文件。支持短名称自动解析（如 `stocks` → `finance/stocks`）。
- `sparkii skills update [name]`：更新已安装技能到最新版本。
- `sparkii skills remove <name>`：卸载技能，清理 `~/.sparkii/skills/` 下的文件。
- `sparkii skills search <query>`：跨来源统一搜索技能。

**配置项**（`config.yaml` 中 `skills.*` 节点）：
- `skills.auto_install`：是否自动安装 Agent 推荐的技能（默认 false）。
- `skills.sources`：配置额外的技能来源仓库。
- `skills.trust_policy`：技能信任策略，控制不同信任级别的安装与执行行为。

**Blueprints 集成**：安装包含 `blueprint:` 块的 SKILL.md 时，系统不会自动创建 Cron 任务，而是向 `cron/suggestions.py` 注册一条建议，用户通过 `sparkii cron suggestions accept` 或 `/cron suggestions accept` 确认后才生效。这确保了 consent-first 原则。

**直接调用**：安装后可通过 `python3 ~/.hermes/skills/<domain>/<skill>/scripts/*.py` 直接在终端执行技能脚本，无需通过 Agent 对话。脚本接受 `--help` 参数输出用法说明。Agent 在对话中匹配到技能意图时，也会以工具调用的方式执行这些脚本。
