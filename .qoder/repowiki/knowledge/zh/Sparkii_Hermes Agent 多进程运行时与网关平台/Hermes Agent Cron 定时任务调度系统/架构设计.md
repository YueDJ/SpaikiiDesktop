模块以 `scheduler.py`（tick 主循环、作业解析与执行）、`jobs.py`（jobs.json 读写、调度表达式解析、心跳文件）为核心，`executions.db` 通过 `executions.py` 维护不可变执行审计账本；`lifecycle_guard.py` 在创建阶段拦截可能触发 gateway 重启的 shell 命令；`monitor.py` 提供 monitor_script/url 的哈希去重变更检测；`blueprint_catalog.py` / `suggestion_catalog.py` / `suggestions.py` / `notepad.py` 提供预置作业模板与提示词目录；`scripts/classify_items.py` 是示例脚本。

依赖方向：`scheduler` → `jobs` + `executions` + `monitor` + `lifecycle_guard`；CLI/gateway 仅通过 `cron/__init__.py` 暴露 `create_job/get_job/list_jobs/remove_job/update_job/pause_job/resume_job/trigger_job/tick/JOBS_FILE` 等有限接口。跨进程并发通过 `fcntl/msvcrt` 对 `.jobs.lock` 加锁，进程内并发由 `concurrent.futures.ThreadPoolExecutor`（并行池 + 单线程顺序池）+ `_ReadWriteLock` 保护共享 `TERMINAL_CWD` 环境变量；每 profile 独立 `SPARKII_HOME/cron` 目录，通过 `use_cron_store()` ContextVar 切换存储根。
