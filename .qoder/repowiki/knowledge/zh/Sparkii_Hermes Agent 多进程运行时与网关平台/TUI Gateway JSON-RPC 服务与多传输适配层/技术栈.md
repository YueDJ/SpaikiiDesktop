TUI Gateway 模块的技术栈围绕异步 JSON-RPC 通信与多传输抽象构建。

核心通信层使用 Python syncio 事件循环驱动 JSON-RPC 协议，消息格式为换行分隔的 JSON 对象（与 stdio 和 WebSocket 共享同一协议）。	ransport.py 定义 Transport Protocol（write/close），通过 contextvars.ContextVar 实现请求级传输绑定，使 handler 代码与底层 I/O 完全解耦。StdioTransport 使用 	hreading.Lock 保护 sys.stdout 的并发写入，TeeTransport 实现主通道 + 多个 best-effort 副通道的镜像写入。WSTransport（ws.py）通过 syncio.run_coroutine_threadsafe 将线程池中的 handler 写入安全投递到 WebSocket 事件循环。

终端 UI 层面，Ink/React 终端 UI（ui-tui/）通过 Node.js 子进程与 Gateway 的 stdio JSON-RPC 通道通信。TypeScript 类型定义确保 RPC 方法名、参数和返回值的类型安全。WebSocket 接入（ws.py，477 行）支持浏览器 Dashboard 与桌面应用通过 FastAPI WebSocket 端点连接，复用同一套 dispatch 与所有 handler。高频流式事件（message.delta、easoning.delta、	hinking.delta）通过 33ms 合并窗口降低事件循环唤醒开销（约 30fps 帧率）。

并发控制方面，server.py 使用 concurrent.futures.ThreadPoolExecutor 将长耗时 RPC（slash.exec、session.resume、billing 等）路由到工作池，避免阻塞 stdin 读取循环。内置 _SlashWorker 持久化子进程用于执行 / 命令。host_supervisor.py（577 行）和 compute_host.py（893 行）管理宿主/计算主机的生命周期。Panic 日志机制将未处理异常追加到 ~/.sparkii/logs/tui_gateway_crash.log 并向 stderr 输出一行摘要供 TUI 的 Activity 面板显示。
