构建、部署与运维脚本基础设施由 scripts/ 运维脚本、docker/ 容器配置和 
ix/ Nix flake 开发环境定义三部分组成，支撑 Sparkii 从开发到生产的全生命周期。

scripts/ 目录包含 39+ 个自动化脚本，按功能域分类：模型与技能构建（uild_model_catalog.py 构建远程模型目录 JSON、uild_skills_index.py 构建技能搜索索引）、环境检查（check-windows-footguns.py 814 行检测 Windows 常见陷阱、check_subprocess_stdin.py 检查子进程 stdin 兼容性）、开发辅助（dev-sandbox.sh 创建隔离开发环境、desktop-update.ps1 桌面应用更新脚本）、CI/CD（ci/ 子目录包含 ssemble_review_comment.py PR 审查评论组装、classify_changes.py 变更分类、e2e_screenshot_status.py 截图状态检查、emit_review_status.py 审查状态发射、lockfile_diff.py 锁文件差异分析、publish_e2e_evidence.py E2E 证据发布、	imings_report.py 构建时间报告等）。其他脚本包括 dd_contributor.py（贡献者管理）、contributor_audit.py（贡献者审计）、docker_config_migrate.py（Docker 配置迁移）、discord-voice-doctor.py（Discord 语音诊断）。

docker/ 目录包含完整的容器化配置：Dockerfile（基于 s6-overlay 的多阶段构建）、s6-rc.d/（服务依赖图定义，main-sparkii 和 dashboard 两个服务）、cont-init.d/（初始化脚本：权限设置、profile reconciliation）、entrypoint.sh / entrypoint-dispatch.sh（入口调度）、main-wrapper.sh（主进程包装，支持优雅关闭和信号转发）、stage2-hook.sh（591 行二级初始化，处理首次启动环境配置）、sparkii-exec-shim.sh（执行兼容层）、	ini-shim.sh（init 系统兼容）。docker-compose.yml 和 docker-compose.windows.yml 提供开箱即用的编排配置。


ix/ 目录（16 个文件）定义 Nix flake 开发环境，提供可复现的工具链（Python、Node.js、Git、ripgrep 等），通过 lake.nix 和 lake.lock 锁定所有依赖版本。pyproject.toml 管理 Python 包元数据与依赖（使用 uv 包管理器），setup.py 提供传统 setuptools 兼容。
