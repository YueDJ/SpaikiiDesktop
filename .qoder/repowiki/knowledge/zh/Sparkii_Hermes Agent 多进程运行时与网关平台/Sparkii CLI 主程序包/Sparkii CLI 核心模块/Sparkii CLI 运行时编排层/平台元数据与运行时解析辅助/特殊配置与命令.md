平台元数据与运行时解析辅助模块的配置入口分散在多个 CLI 子命令与配置文件中。

config.yaml 中与平台相关的配置节包括：platform 键指定当前活跃的消息平台（如 cli、	elegram、discord），platform_toolsets 键按平台名存储每个平台启用的工具集列表（由 	ools_config.py 管理），skills.platform_disabled 键按平台名存储禁用的技能列表（由 skills_config.py 管理）。平台注册表本身通过 platforms.py 的 PLATFORMS OrderedDict 硬编码，插件动态注册的平台通过 gateway.platform_registry 合并到菜单中。

sparkii doctor 命令（位于 sparkii_cli/doctor.py）执行运行时环境健康检查，包括：验证 Python 解释器版本与 SQLite 链接版本（调用 sqlite_runtime.probe_sqlite_runtime()）、检测 WAL-reset 漏洞并给出升级建议、检查 .sparkii 目录权限、验证核心依赖是否可用、测试网络连通性等。该命令是用户排查环境问题的首选入口。

SQLite 运行时参数调优方面，sqlite_runtime.py 的 is_sqlite_wal_reset_vulnerable() 函数实现了精确的版本范围判定：SQLite 3.7.0 至 3.51.3 之间的大多数版本存在 WAL 文件在 checkpoint 后可能损坏的 bug，仅 3.44.6+、3.50.7+ 和 3.51.3+ 三个补丁版本修复了此问题。当检测到漏洞版本时，系统会在日志中发出警告并建议用户升级 Python（因为 SQLite 版本由 Python 解释器静态链接决定）。此外，sqlite_safe_read.py（415 行）和 sqlite_util.py（49 行）提供安全读取 SQLite 数据库的工具函数，处理并发访问与损坏恢复。

运行时提供商解析还支持环境变量覆盖：SPARKII_PYTHON 可指定用于探测的 Python 解释器路径，SPARKII_SQLITE_RUNTIME_PROBE_TIMEOUT 控制子进程探测超时（默认 30 秒）。在 Windows 上，windows_ssh_runtime.py（508 行）额外处理通过 SSH 远程访问 Windows 主机时的运行时探测与路径转换。
