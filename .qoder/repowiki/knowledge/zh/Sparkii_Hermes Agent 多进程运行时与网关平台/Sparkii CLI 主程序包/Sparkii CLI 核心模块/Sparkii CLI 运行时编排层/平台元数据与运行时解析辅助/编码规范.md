- 对外暴露的公共函数采用“尽力而为”语义：当外部依赖（如 `gateway.platform_registry`）不可用时通过 try/except 静默降级并返回默认值，保证导入安全。
- 运行时解析按 provider 字符串进行 if/elif 分支选择，每个分支独立推导 `api_mode`、`base_url`、`api_key`，最终统一组装为包含 `provider/api_mode/base_url/api_key/source/credential_pool/requested_provider` 字段的字典返回。
- 对来自配置的原始值一律先 strip().lower() 再校验，并通过 `_parse_api_mode()` 等白名单函数过滤非法枚举值后再写入结果。
- 自定义 provider 查找同时兼容新旧两种配置形态（新式 `providers:` 字典与旧式 `custom_providers:` 列表），并在命中时通过 `_lift_extra_headers()` / `_lift_max_output_tokens()` 等专用提升函数拷贝可选字段。
- SQLite 探测采用“子进程隔离 + JSON 序列化”模式：用独立脚本收集 `sqlite_version_info`、`sqlite_source_id` 等元信息，再以 `SQLiteRuntimeInfo` dataclass 封装返回，使调用方无需直接 import sqlite3 即可安全探测。
