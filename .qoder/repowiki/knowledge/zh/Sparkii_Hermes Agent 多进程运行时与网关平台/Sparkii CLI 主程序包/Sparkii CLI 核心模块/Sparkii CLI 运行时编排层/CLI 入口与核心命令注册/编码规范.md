- 子命令通过 `from sparkii_cli.subcommands.<name> import build_<name>_parser` 统一注册到主解析器的 subparsers，保持入口与具体命令实现的解耦。
- 需要跨 relaunch 透传的 argparse flag 使用 `_inherited_flag` 包装而非直接 `add_argument`，以便 relaunch 逻辑通过 `action.inherit_on_relaunch` 属性识别。
- 斜杠命令以 `CommandDef` 数据类条目集中声明在 `COMMAND_REGISTRY` 列表中，并通过 `cli_only`、`gateway_only`、`busy_policy`、`execute` 等字段描述行为，而不是分散在各处 if-chain。
- 对可选重型依赖（如 prompt_toolkit、plugins、agent.skill_utils）采用 try/except ImportError 或延迟 import，确保 gateway/test 环境也能安全导入该模块。
- 启动期关键决策（TUI/CLI 选择、IPv4 强制、redact_secrets）在正式 config 加载前通过最小化 YAML 读取完成，并将结果缓存到模块级变量以避免重复 I/O。
