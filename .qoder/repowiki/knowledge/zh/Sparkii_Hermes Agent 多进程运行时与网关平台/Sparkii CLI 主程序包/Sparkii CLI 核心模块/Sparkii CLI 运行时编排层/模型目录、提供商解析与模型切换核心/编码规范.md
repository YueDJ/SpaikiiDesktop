- 所有外部 I/O（HTTP 拉取、磁盘读写、config 加载）都包裹在 try/except 中并记录日志后返回 None/空结构，确保 CLI 在网络或配置异常时仍能降级运行。
- 提供商/模型标识统一先经 `normalize_provider()` 小写化再查表，避免大小写敏感导致的重复注册。
- 可配置项采用“懒加载 + 默认值填充”模式：如 `_load_catalog_config()`、`_load_direct_aliases()` 仅在首次使用时读取 config，并以安全默认值兜底。
- 对外 API 返回 None 表示“不可用”，由调用方自行决定回退到内置硬编码列表，而不是抛出异常。
- 通过 dataclass（`ProviderDef`、`ModelSwitchResult`、`ModelFlagParseResult`、`ModelSwitchRequest`）集中承载结构化结果，替代散落的 namedtuple 或 dict。
- 对易变的外部资源（模型目录、别名表）使用模块级全局缓存 + mtime/TTL 失效机制，避免每次调用都触发网络请求。
