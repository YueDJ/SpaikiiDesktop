本模块由三个职责互补的文件组成：
- `plugins.py` 实现 Hermes 插件系统，从四个来源（bundled、用户 `~/.sparkii/plugins`、项目 `.sparkii/plugins`、pip entry-point `sparkii_agent.plugins`）扫描并加载插件，通过 `PluginManifest`/`LoadedPlugin` 描述元数据与运行时状态，并通过 `PluginContext` 暴露 `register_tool`、`register_*_provider`、`register_platform`、`register_cli_command`、`register_command`、`inject_message` 等扩展点；所有 provider 注册均做类型校验后写入对应 registry，覆盖内置工具需显式 `allow_tool_override` 授权。
- `skills_hub.py` 提供 `sparkii skills` CLI 与 `/skills` slash command 的统一入口，核心逻辑集中在 `do_search`/`do_browse`/`do_install`/`do_inspect`/`do_list` 等 `do_*` 函数中，调用层仅负责参数解析与 Rich 表格渲染；实际检索、下载、隔离、安全扫描、锁定文件管理委托给 `tools.skills_hub` 与 `tools.skills_guard`，安装流程遵循 quarantine → scan (`scan_skill_cached`) → policy check (`should_allow_install`) → install 的安全链，并支持 URL 源的技能名/分类交互提示与 blueprint 自动化建议注册。
- `tools_config.py` 维护统一的工具配置 UI 与持久化，集中声明 `CONFIGURABLE_TOOLSETS`、`TOOL_CATEGORIES`（含各 provider 的 env 变量、post_setup 钩子、Nous 订阅集成）、默认关闭集合 `_DEFAULT_OFF_TOOLSETS`，并通过 `_get_effective_configurable_toolsets()` 动态合并插件提供的 toolset；保存位置为 `~/.sparkii/config.yaml` 的 `platform_toolsets` 键，同时提供 `install_cua_driver`、`_pip_install` 等 post-setup 能力。
依赖方向单向向外：`skills_hub.py` 与 `tools_config.py` 均通过延迟 import 调用 `tools.*` 与 `agent.*`，避免循环依赖；`plugins.py` 被 `tools_config.py` 反向引用以注入插件 toolset，形成 `tools_config → plugins → tools/agent` 的层次。
