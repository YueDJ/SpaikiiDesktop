本模块由三个相互独立的辅助文件组成，均被上层 CLI/gateway/cron 等组件导入使用：
- `platforms.py`：集中维护 `PLATFORMS: OrderedDict[str, PlatformInfo]` 静态平台清单（label + default_toolset），并通过 `platform_label()` / `get_all_platforms()` 将内置平台与 `gateway.platform_registry` 动态注册的插件平台合并，作为 skills_config 与 tools_config 的唯一来源。
- `runtime_provider.py`：核心运行时解析层，围绕 `_resolve_runtime_from_pool_entry()` 按 provider 分支（openai-codex、xai-oauth、qwen-oauth、minimax-oauth、anthropic、openrouter、nous、copilot、azure-foundry、opencode-*、lmstudio 及通用 else）推导 `api_mode`、`base_url`、`api_key`，并借助 `_detect_api_mode_for_url()`、`_fallback_api_mode()`、`_provider_supports_explicit_api_mode()`、`_maybe_apply_codex_app_server_runtime()` 等内部函数实现 URL 自动推断、配置覆盖与 Codex app-server 路由；同时提供自定义 provider 查找（`_get_named_custom_provider`）、URL/模型反向映射（`find_custom_provider_identity*`）和裸 custom 身份恢复（`canonical_custom_identity`）。
- `sqlite_runtime.py`：纯标准库依赖的轻量探针，通过 `subprocess` 在目标 Python 解释器中运行内嵌脚本获取 SQLite 版本信息，并用 `is_sqlite_wal_reset_vulnerable()` 判定是否受 WAL reset 漏洞影响，供安装器/更新器在第三方依赖就绪前安全调用。
依赖方向单向向外：本模块仅依赖 `sparkii_cli.auth/config/providers`、`agent.credential_pool`、`sparkii_constants` 等底层包，不被同级其他文件反向引用。
