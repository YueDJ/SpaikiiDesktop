Sparkii CLI 主程序包是系统的命令行入口与运行时编排层，以 sparkii_cli/ 目录为物理载体，统一装配配置、认证、模型、插件、子命令及 Web/代理服务。该模块的核心是 main.py（500KB），作为主入口负责早期启动优化、环境检测、日志初始化、子命令解析器装配与分发，支持 46 个子命令模块覆盖聊天、配置、会话、网关、插件、模型等全方位功能。

CLI 的关键能力包括：配置管理（config.py + config_defaults.py）提供分层配置加载、缓存与安全管理，支持用户配置、项目配置、环境变量的智能合并与迁移；认证系统（auth.py + auth_commands.py）统一处理多提供商的 OAuth、API Key、令牌轮换与持久化；模型管理（models.py + model_setup_flows.py）支持模型发现、切换、成本控制与提供商适配；插件系统（plugins.py + plugins_cmd.py）提供插件加载、生命周期管理与命令扩展。

交互式体验由 cli.py 提供，基于 prompt_toolkit 构建 REPL 界面，支持历史、补全、富文本输出、快捷键绑定与 TUI 模式自动检测。斜杠命令系统（commands.py）集中定义所有 / 命令及其行为策略，支持忙时处理、权限控制与平台特定扩展。会话管理（sessions_cmd.py）提供会话列出、导出、删除、修复、恢复等能力，支持多种格式（JSONL、HTML、Markdown、Trace）与脱敏选项。

该模块与 Agent 运行时紧密协作：通过 agent_import.py 动态导入 Agent 模块，避免冷启动延迟；通过 runtime_provider.py 提供运行时环境检测与配置注入；通过 web_server.py 暴露 Web Dashboard API 与管理接口。整体架构采用 Mixin 模式组织功能（cli_agent_setup_mixin.py、cli_billing_mixin.py、cli_commands_mixin.py），确保代码模块化与可维护性。
