Sparkii CLI 主程序包（sparkii_cli/）是整个 Agent 平台的命令行入口与用户交互层，包含约 190 个 Python 模块，负责命令解析、配置管理、认证流程、模型切换、会话管理、Web 仪表盘、Gateway 控制等所有面向用户的操作。main.py 作为顶层入口（约 12,700 行），注册所有子命令（chat、gateway、cron、config、model、setup、acp 等）并调度到对应的 cmd_* 处理函数。

CLI 支持三种交互模式：经典 REPL（基于 prompt_toolkit 的交互式终端，支持语法高亮、自动补全、斜杠命令）、TUI 模式（基于 curses 的富文本终端界面）与 Web Dashboard（基于 fastapi 的浏览器端 UI，端口 9119）。_parser.py 构建顶层 argparse 解析器，定义全局标志（--profile、--tui、--cli、-c 恢复会话等），所有子命令的元数据集中于 commands.py 的 COMMAND_REGISTRY。

程序包还集成了一系列辅助能力：skills_hub.py（Skills Hub CLI，技能浏览/安装/更新）、kanban.py（任务看板管理）、cron.py（Cron 任务 CLI）、gateway.py（Gateway 服务安装/启动/停止）、sessions_cmd.py（会话浏览/导出/重命名）、doctor.py（环境诊断）、update_cmd.py（自动更新）、pty_bridge.py/win_pty_bridge.py（PTY 桥接，支持交互式终端命令）。所有模块遵循 sparkii_logging 的集中日志规范，通过 sparkii_constants.get_sparkii_home() 统一解析 home 路径。

配置系统（config.py，约 5,500 行）管理 ~/.sparkii/config.yaml 与 .env 文件，支持三层配置合并（用户级、项目级、环境变量）、配置迁移（config_migrations.py）、损坏备份恢复、以及 YAML 安全加载。认证模块（auth.py、nous_auth_keepalive.py）处理多提供商凭据池、OAuth 流程与凭据持久化。
