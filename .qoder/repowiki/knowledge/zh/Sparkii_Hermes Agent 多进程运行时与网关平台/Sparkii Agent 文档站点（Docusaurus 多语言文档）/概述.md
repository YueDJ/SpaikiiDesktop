文档站点基于 Docusaurus 3 构建，是 Hermes Agent 的官方文档中心，提供英文（`en`）与简体中文（`zh-Hans`）双语内容。站点部署于 `https://sparkii-agent.nousresearch.com/docs/`，组织名为 `NousResearch`，项目名为 `sparkii-agent`。

文档内容按六大目录组织：`getting-started/`（快速入门与安装指南）、`user-guide/`（CLI 使用、配置管理、消息平台接入等用户操作指南）、`developer-guide/`（架构设计、插件开发、工具扩展等开发者参考）、`guides/`（自动化蓝图、浏览器使用、MCP 集成等专题教程）、`integrations/`（Telegram、WhatsApp、Discord、Signal 等平台集成指南）、`reference/`（CLI 命令参考、配置项清单、工具列表等速查手册）。

站点支持 Mermaid 图表渲染（通过 `@docusaurus/theme-mermaid`），文档中可直接嵌入流程图与架构图。搜索功能使用 Algolia DocSearch 提供云端全文检索，替代了原先的本地 lunr 索引（约 16 MB），显著减少客户端下载体积。客户端重定向插件（`@docusaurus/plugin-client-redirects`）处理已重命名页面的 URL 映射，确保旧书签不失效。

国际化通过 Docusaurus 内置 i18n 插件实现，`i18n/zh-Hans/` 目录存储简体中文翻译文件。导航栏提供语言切换下拉菜单，支持在英文与简体中文之间即时切换。Prism 语法高亮支持 bash、yaml、json、python、toml 等语言。站点主题默认深色模式，尊重用户系统偏好。
