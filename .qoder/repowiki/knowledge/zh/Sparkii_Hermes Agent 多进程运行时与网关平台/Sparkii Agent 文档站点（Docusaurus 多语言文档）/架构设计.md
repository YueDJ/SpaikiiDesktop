模块以 Docusaurus Classic Preset 为核心，通过 `docusaurus.config.ts` 配置站点元信息、Algolia DocSearch、Mermaid 主题、i18n（默认 en，额外 zh-Hans）、客户端重定向（`@docusaurus/plugin-client-redirects`）以及 `/docs/` 路由基路径；导航结构由 `sidebars.ts` 集中声明，将 docs/ 下的 Markdown/MDX 按 Getting Started / Using Hermes / Features / Messaging Platforms / Integrations / Guides & Tutorials / Developer Guide / Reference 等分类组织，并通过 `_category_.json` 控制折叠行为。

内容分层：
- `website/docs/`：主站文档源，按 user-guide、developer-guide、guides、integrations、reference、getting-started 分目录，每个子目录含 `_category_.json` 定义侧边栏分组。
- `website/i18n/zh-Hans/docusaurus-plugin-content-docs/current/`：与英文目录一一对应的中文翻译副本，缺失文件即该页面未翻译。
- `website/src/`：自定义 React 组件（AutomationBlueprintsCatalog、UserStoriesCollage）、全局样式 `src/css/custom.css`、数据 `src/data/userStories.json` 以及独立页面 `src/pages/skills/index.tsx`（Skills 入口）。
- `website/static/`：静态资源（favicon、logo、模型目录 JSON 等）。
- `website/scripts/`：预构建脚本（`prebuild.mjs`、`extract-automation-blueprints.py`、`generate-skill-docs.py`、`generate-llms-txt.py`），在 `npm run start/build` 前自动执行以生成动态内容。
- `docs/`：仓库根级设计/架构/安全等非站点化文档，不参与 Docusaurus 构建，仅作为源码内文档存在。

依赖方向：`sidebars.ts` → `docs/*` 中的 Markdown；`src/components` 通过 MDX 引用；预构建脚本读取仓库其他位置的数据并产出到 `static/` 或 `docs/reference/`，再由 Docusaurus 编译为静态站点。
