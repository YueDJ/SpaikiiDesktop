- 每个文档子目录通过同名的 `_category_.json` 文件声明侧边栏分组标题与折叠状态，而非在 sidebars.ts 中硬编码所有层级。
- 多语言支持采用 Docusaurus i18n 约定：英文原文位于 `website/docs/<locale>/...`，中文翻译镜像放置于 `website/i18n/zh-Hans/docusaurus-plugin-content-docs/current/<same-path>`，缺失文件表示该页面尚未翻译。
- 侧边栏条目统一使用相对路径字符串（如 `'user-guide/features/tools'`）引用 Markdown 文件，避免使用绝对 URL，便于本地开发与部署路径切换。
- 动态生成的参考内容（自动化蓝图、技能目录、模型清单）通过 `scripts/` 下的 Python/Node 预构建脚本在 `prebuild` 阶段生成，再被 MDX 页面消费，实现文档与代码库状态同步。
- 旧版文档 URL 通过 `@docusaurus/plugin-client-redirects` 的 redirects 表进行静态重定向，以兼容历史链接而不引入服务端逻辑。
- Markdown 文档统一启用 Mermaid 图表（`markdown.mermaid: true`），并在 `themeConfig.prism.additionalLanguages` 中声明 bash/yaml/json/python/toml 等常用语言的高亮支持。
