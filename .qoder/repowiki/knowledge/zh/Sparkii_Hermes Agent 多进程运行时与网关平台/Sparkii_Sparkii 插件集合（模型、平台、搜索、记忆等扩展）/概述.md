plugins/ 目录是 Sparkii/Hermes 的内置插件仓库，按能力域划分子目录，包含模型提供商、消息平台、搜索引擎、浏览器、图像/视频生成、记忆系统、上下文引擎、仪表盘认证、Cron 调度、可观测性、安全指导等扩展。

模型提供商插件（model-providers/<provider>/）每个实现一个 ProviderProfile（继承自 providers.base.ProviderProfile），在模块末尾实例化并通过 egister_provider() 向宿主注册，由 plugin.yaml 声明 name/kind/version。

消息平台插件（platforms/<channel>/）覆盖 Slack、Telegram、Discord、Teams、WhatsApp、Matrix、DingTalk、飞书、Google Chat、IRC、LINE、Mattermost、SMS、Simplex、企业微信等 20+ 个聊天平台，每个实现 dapter.py 中的 egister(ctx) 入口。

搜索引擎插件（web/<engine>/）和浏览器插件（rowser/<engine>/）分别实现 WebSearchProvider 和 BrowserProvider ABC，支持 Exa、Firecrawl、Tavily、Browserbase、Browser Use 等多种后端。图像/视频生成插件（image_gen/<engine>/、ideo_gen/<engine>/）遵循相同的 provider ABC + get_setup_schema() + is_available() 模式。

记忆系统插件（memory/<store>/）实现 gent.memory_provider.MemoryProvider ABC（包括 holographic、hindsight、mem0、honcho、byterover 等多种存储后端），通过 egister(ctx) 调用 ctx.register_memory_provider(...) 暴露给 agent。上下文引擎插件（context_engine/）通过独立发现路径扫描，实现 ContextEngine ABC，同一时间仅一个引擎可激活（通过 context.engine 配置选择），默认为内置的 ContextCompressor。

其他插件包括：dashboard_auth/（Basic、Drain、Nous、Self-hosted 四种认证方案）、cron_providers/（Chronos 调度实现含 NAS 客户端）、observability/（Langfuse 等可观测性集成）、security-guidance/、spotify/、disk-cleanup/、google_meet/（含音频桥接和 Meet Bot）。

共享基础设施位于根级 plugin_utils.py，提供线程安全的 lazy_singleton 装饰器与 SingletonSlot 类，防止多进程/多线程下重复初始化外部客户端导致的资源泄漏。插件之间相互隔离，仅 import 宿主 API（gent.*、providers.*、	ools.*、sparkii_cli.*），不反向引用。
