模块以 `server.py` 中的 `SparkiiACPAgent(acp.Agent)` 为核心，继承并实现 ACP 协议方法；入口由 `entry.py` 的 CLI（`python -m acp_adapter.entry` / `sparkii acp`）负责加载 `.env`、配置日志（stderr 保留 stdout 给 JSON-RPC）、启动 MCP 工具发现线程，并通过 `acp.run_agent(agent, use_unstable_protocol=True)` 启动事件循环。

内部按职责拆分为多个子模块：
- `session.py`：`SessionManager` + `SessionState` 维护内存中的 AIAgent 实例，并通过 `sparkii_state.SessionDB` 持久化到 `~/.sparkii/state.db`，支持 create/fork/list/load/resume/delete/cleanup 全生命周期，且对 Windows/WSL 路径做双向转换。
- `tools.py`：维护 sparkii 工具名到 ACP `ToolKind` 的映射表，并为每个工具提供专用的结果格式化函数，统一输出为 ACP 文本/diff/content block。
- `events.py`：工厂函数 `make_tool_progress_cb` / `make_step_cb` / `make_thinking_cb` / `make_message_cb` 生成 AIAgent 回调，通过 `safe_schedule_threadsafe` 把 ACP session_update 从工作线程安全投递到主事件循环。
- `permissions.py`：`make_approval_callback` 将 Sparkii 的危险命令审批桥接到 ACP `request_permission`，构建选项集并等待用户选择，超时或异常回退为 deny。
- `edit_approval.py`（未展开阅读但被引用）：基于会话模式（default/accept_edits/dont_ask）自动批准文件编辑。
- `auth.py`：`build_auth_methods` 动态注册终端设置方法与当前 provider 认证方式；`detect_provider` 兼容 Azure Foundry callable api_key。
- `provenance.py`：根据 `parent_session_id` / `end_reason` 推导压缩链根节点与旋转原因，注入 ACP `_meta.sparkii.sessionProvenance`。

依赖方向单向：`server` → `session` / `tools` / `events` / `permissions` / `auth` / `provenance`；所有外部包（`acp`、`sparkii_cli.*`、`run_agent`、`agent.*`）均采用延迟 import，保证模块可被最小环境导入。
