本模块是 `run_agent.py` 中 3600+ 行主文件抽取后的内部包，顶层以扁平的 Python 文件组织 AIAgent 的运行时职责（如 `agent_init.py`、`conversation_loop.py`、`tool_executor.py`、`context_engine.py`、`memory_manager.py`、`prompt_builder.py`、`turn_*` 系列），并通过若干命名子包承载可插拔能力：
- `transports/`：基于 `api_mode` 字符串的传输层注册表（`__init__.py` 中的 `_REGISTRY` + `_discover_transports` 懒加载各 provider），统一将 Anthropic/Codex/Bedrock/ChatCompletions 等后端响应归一化为 `NormalizedResponse`。
- `secret_sources/`：以 `SecretSource` 抽象 + `registry.apply_all` 编排多个外部密钥后端（Bitwarden、1Password、command），共享 `_cache` 原子写入与 TTL 磁盘缓存。
- `lsp/`：通过 `get_service()` 单例懒启动 pyright/gopls/rust-analyzer 等语言服务器进程，按 git workspace 检测启用，并在 atexit 时清理。
- `monitoring/`：以 `emitter` 事件总线解耦生产端与 OTLP 导出消费者，严格保证热路径不阻塞。
- `pet/`：独立于模型调用的 TUI 精灵渲染子系统，提供状态机与 spritesheet 解码。
- `verify/`：环境/配方/运行器的验证流水线。
依赖方向单向向外：顶层文件依赖各子包，子包之间基本无环；AIAgent 实例作为状态载体在各模块间传递，所有 provider/transport/secret_source 均通过显式注册或接口实现接入。
