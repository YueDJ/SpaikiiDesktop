- 每个被测子系统拥有独立子目录（agent、cli、gateway、tools、skills、plugins 等），测试文件以 `test_<feature>.py` 命名并按功能域分组。
- 通过 `tests/conftest.py` 中全局沙箱强制环境变量隔离：清理所有凭据类 env var、设置 `SPARKII_HOME` 为临时目录、固定时区与语言，禁止 `SPARKII_SESSION_*` 继承。
- 子目录级 `conftest.py`（如 acp、cli）提供该子系统专属夹具，复用根 conftest 的全局隔离策略，形成“全局夹具 + 领域夹具”的分层结构。
- 测试用例针对具体缺陷编号命名（如 `test_rotation_flush_persisted_boundary_68196.py`、`test_cascading_interrupt_6600.py`），便于回溯关联 issue。
- 异步与并发相关测试显式使用 `asyncio` 与 `pytest-asyncio`，并通过 `run_tests_parallel.py` 保证跨文件隔离，避免模块级缓存污染。
- TypeScript 测试统一采用 Vitest 的 `*.test.ts` 命名约定，并通过 `vitest.config.ts` 集中配置 Node 环境与匹配规则。
