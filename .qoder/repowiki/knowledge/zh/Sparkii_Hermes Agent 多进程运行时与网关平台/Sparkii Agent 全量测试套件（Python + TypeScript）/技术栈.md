测试技术栈涵盖 Python 与 TypeScript 两大生态，分别服务于后端逻辑与前端/桌面功能验证。

**Python 测试框架**：基于 pytest 构建，配合 `pytest-xdist` 实现多进程并行测试。`conftest.py` 提供全局 fixture 层，包括环境变量隔离（清除所有 `_API_KEY`、`_TOKEN`、`_SECRET` 等凭据变量）、临时 `SPARKII_HOME` 目录创建与清理、SQLite 数据库连接复用、以及 `monkeypatch` 级别的 Agent 运行时 mock。测试文件命名遵循 `test_*.py` 规范，使用 `@pytest.mark` 进行分类标记（如 `@pytest.mark.slow`、`@pytest.mark.integration`）。

**断言与快照**：大量使用 `json` 模块进行结构化数据比对，测试 fixtures 中预存 JSON 快照文件用于回归检测。`unittest.mock.patch` 广泛用于隔离外部依赖（OpenAI API、文件系统、网络请求）。自定义断言辅助函数处理时间戳模糊比对、UUID 格式校验等场景。

**TypeScript 测试框架**：使用 Vitest 4.1.10 作为测试运行器，TypeScript 6.0.3 提供类型检查。`vitest.config.ts` 配置 `node` 环境与 `**/*.test.ts` 文件匹配模式。`tsconfig.json` 启用严格类型检查。devDependencies 包含 `plist`（macOS plist 解析/构建）和 `@types/plist` 类型定义。

**CI 集成**：Python 测试通过 `scripts/run_tests.sh` 统一入口运行，该脚本处理 xdist worker 数量、CPU 核心数等 CI 环境适配。TypeScript 测试通过 `npm run check` 串联类型检查、测试执行与 ESLint 代码规范检查。Docker 集成测试（`tests/docker/`）验证容器化部署场景。
