全量测试套件覆盖 Sparkii Agent 平台的全部子系统，包括 Agent 运行时、CLI 主程序、Gateway 网关、Hermes 工具集、插件系统、前端脚本等。Python 侧测试位于 `tests/` 目录，按模块分为 34 个子目录（cron、tools、gateway、agent、sparkii_cli、tui_gateway 等），包含约 2853 个测试文件。TypeScript 侧测试位于 `tests-js/`，验证前端脚本与桌面应用相关的 Node.js 模块。

测试体系遵循严格的隔离性原则：每个测试运行在独立的临时 `SPARKII_HOME` 中，所有 API Key 环境变量在测试前被清除，运行时固定为 TZ=UTC、LANG=C.UTF-8、PYTHONHASHSEED=0，确保本地运行与 CI 环境一致。`conftest.py` 提供全局 fixture，包括 `_isolate_env`（环境隔离）、SQLite 连接管理、mock Agent 实例等基础设施。

Python 测试支持 `pytest-xdist` 并行执行，测试数据与断言大量使用 JSON 快照比对。Cron 子系统拥有独立的 44 个测试文件，覆盖任务创建/调度/执行/恢复/跨进程锁/配置文件隔离等场景。Gateway 测试模拟多平台消息接入与会话管理。Agent 测试覆盖对话循环、工具调用、上下文压缩、推理超时等核心路径。集成测试（`tests/integration/`）验证端到端流程，压力测试（`tests/stress/`）验证高并发场景的稳定性。

TypeScript 测试使用 Vitest 4.1.10 + TypeScript 6.0.3，配置于 `tests-js/vitest.config.ts`。当前覆盖桌面应用构建验证、plist 解析、npm 依赖同步等 Node.js 侧功能。`package.json` 提供 `npm run test`（Vitest 执行）和 `npm run check`（类型检查 + 测试 + lint）两条 CI 入口。
