运行时与插件子系统是 Hermes Agent 的进程级核心，负责 AI 代理的完整生命周期管理——从初始化、对话循环、工具执行到会话持久化。`agent/agent_init.py` 实现了 `AIAgent.__init__` 的主体逻辑（约 2,800 行，60+ 参数），包括提供商自动检测、凭据解析、上下文引擎引导、工具护栏配置等。

**异步运行时**：Agent 基于 Python asyncio 事件循环运行，通过线程池桥接同步的工具执行与异步的对话流。`conversation_loop.py` 实现核心对话循环，`chat_completion_helpers.py` 封装 OpenAI SDK 的 Chat Completion / Responses API 调用。`retry_utils.py` 使用 `tenacity` 库实现带指数退避的重试机制。`turn_context.py` 管理每轮对话的上下文状态。

**LSP 集成**：`agent/lsp/` 提供完整的 Language Server Protocol 客户端实现，通过 JSON-RPC over stdin/stdout 与语言服务器子进程通信。`client.py` 管理文档同步（全量替换策略）、诊断推送与超时重试。`manager.py` 运行独立的 asyncio 事件循环于后台线程，使同步的文件操作层可以调用异步的 LSP 服务。支持 clangd、eslint 等主流语言服务器。

**监控与可观测**：`agent/monitoring/` 提供 OpenTelemetry OTLP 导出能力（`otlp_exporter.py`），将 Gateway 健康事件映射为 OTel Span 并发送到配置的端点。`emitter.py` 实现事件分发器，`events.py` 定义事件类型，`gateway_health.py` 采集 Gateway 健康指标。OTLP SDK 作为可选依赖，通过 `tools/lazy_deps.py` 按需安装。

**Pet 精灵图集**：`agent/pet/` 实现终端宠物精灵图渲染系统。`render.py` 支持四种图形协议：Kitty（kitty/Ghostty/WezTerm）、iTerm2（iTerm2/WezTerm）、Sixel（xterm/foot/mlterm）与 Unicode 半块降级。`store.py` 管理精灵状态持久化，`constants.py` 定义帧尺寸与状态枚举。图像解码依赖 Pillow（核心依赖），不可用时优雅降级为文本模式。
