Sparkii Hermes Agent 的运行时核心是整个系统的神经中枢，负责协调 AI 代理的完整生命周期。该模块以 agent/ 目录为物理载体，包含 425KB 的 conversation_loop.py 作为对话循环主引擎，驱动用户请求的端到端处理流程。在初始化阶段，agent_init.py 通过 init_agent 函数完成提供商自动检测、传输缓存预热、上下文引擎生命周期管理等关键设置，确保代理能够快速响应首次请求。

运行时核心的关键能力包括：对话循环管理（run_conversation）负责系统提示恢复、上下文压缩触发、模型调用、工具调度、重试与降级策略；工具执行引擎（tool_executor.py）提供并发执行、授权门控、预算控制与增量持久化功能；上下文压缩系统（context_compressor.py + conversation_compression.py）通过智能摘要算法保护头部与尾部关键信息，避免超出模型上下文限制；凭据与秘密源管理（credential_pool.py + secret_sources/）统一处理多提供商的认证与密钥轮换。

该模块与 tools/ 目录紧密协作，通过 ToolRegistry 注册表发现并分发工具调用；与 gateway/ 交互获取会话上下文与平台能力信息；通过 transports/ 子目录适配不同 LLM 提供商的 API 差异（如 Anthropic、Bedrock、Gemini、Codex 等）。监控子系统（monitoring/）提供实时指标采集，LSP 集成支持代码智能感知，Petdex 展示层提供可视化的代理状态界面。整体架构采用模块化设计，通过插件机制支持第三方扩展，确保系统在高负载对话场景下的稳定与高效。
