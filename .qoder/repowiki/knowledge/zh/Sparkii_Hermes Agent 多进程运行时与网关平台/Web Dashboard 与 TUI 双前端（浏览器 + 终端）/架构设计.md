本模块包含两个独立的前端应用，通过同一后端 Gateway 通信：

- `web/`：浏览器端仪表盘。入口 `src/main.tsx` 用 `createRoot` 挂载 React 19 根组件，外层包裹 `BrowserRouter`、`I18nProvider`、`ThemeProvider`、`SystemActionsProvider`；`App.tsx` 使用 react-router v8 的 `Routes/Route` 声明式路由，所有页面（Sessions、Models、Config、Chat 等）通过 `React.lazy` 按需加载以减小首屏体积。布局由侧边栏 + 主内容区构成，并通过 `@nous-research/ui` 设计系统组件与 Tailwind CSS 4 构建样式。插件体系位于 `src/plugins/`，通过 `exposePluginSDK` 在渲染前暴露 SDK，允许外部 `<script>` 注入的插件动态注册到 `PluginSlot` 插槽并覆盖/扩展内置路由。
- `ui-tui/`：Node.js 终端 TUI。入口 `src/entry.tsx` 启动后检查 TTY、重置终端模式、清理屏幕，创建 `GatewayClient` 连接后端，再异步 `import('@hermes/ink')` 与 `./app.js`，调用 `ink.render(<App gw={gw} />)` 渲染。应用状态集中在 `src/app/`（`useMainApp`、`turnController`、`submissionCore`、`gatewayContext` 等），UI 组件在 `src/components/`，领域模型在 `src/domain/`，通用工具在 `src/lib/`。内存监控、优雅退出、信号处理在入口层集中管理。
- `packages/hermes-ink/`：TUI 自研 Ink 框架子包，实现 React reconciler 之上的终端渲染管线（`ink/` 下的 renderer、screen、cursor、termio、events、layout 等），对外仅暴露 `index.js`、`text-input.js` 两个入口，被上层 TUI 通过 `file:` 引用。

依赖方向：`web` 与 `ui-tui` 均通过 `file:../apps/shared` 复用共享类型与常量；两者不互相依赖，仅通过 HTTP/WebSocket 与后端 Gateway 交互。
