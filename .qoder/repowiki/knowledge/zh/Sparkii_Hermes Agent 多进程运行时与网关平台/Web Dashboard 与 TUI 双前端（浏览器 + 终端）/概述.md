Web Dashboard 与 TUI 双前端为 Sparkii 提供浏览器和终端两种交互界面，共享同一后端（TUI Gateway JSON-RPC 服务）和传输层协议。

web/ 目录是基于 Vite + React 的浏览器 Dashboard，技术栈包括 React 19、TypeScript、Tailwind CSS 4、React Router 8、xterm.js（终端模拟）、@nous-research/ui（Nous 设计系统组件库）、Motion（动画）、GSAP、@react-three/fiber（3D 渲染）、@observablehq/plot（数据可视化）。Dashboard 通过 @sparkii/shared 包（pps/shared/）与后端通信，该共享包封装了 Gateway 的 JSON-RPC 客户端逻辑，同时被浏览器 Dashboard 和桌面应用复用。Dashboard 支持完整的 Agent 交互：聊天会话管理、流式响应展示、工具活动面板、配置管理、文件浏览、认证管理等。

ui-tui/ 目录是基于 Ink/React 的终端 UI，使用 Node.js 实现，通过 stdio JSON-RPC 通道与 TUI Gateway 通信。Ink 将 React 组件渲染到终端字符网格，提供与 Web Dashboard 功能对等的终端体验。TUI 的 TypeScript 类型定义确保 RPC 方法名、参数和返回值的类型安全。

两个前端共享 pps/shared/ 包中的传输层抽象、状态管理原子和类型定义，确保 API 调用方式一致。桌面应用（pps/desktop/）进一步复用 @sparkii/shared 并在此基础上增加 Electron 原生能力（文件系统访问、Git 操作、窗口管理、自动更新）。三种前端（浏览器、终端、桌面）通过同一套 Gateway 后端统一驱动 Agent，共享会话历史、配置和技能。

web/ 的构建通过 Vite 完成（
pm run build），输出静态文件可由 Gateway 内置的 HTTP 服务器托管或部署到 CDN。开发模式下（
pm run dev）使用 Vite 的 HMR 热重载。测试使用 Vitest 框架。
