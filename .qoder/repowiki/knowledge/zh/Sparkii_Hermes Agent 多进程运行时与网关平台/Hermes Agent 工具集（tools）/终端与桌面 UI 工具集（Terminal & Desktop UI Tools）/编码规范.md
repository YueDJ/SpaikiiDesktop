- 每个桌面 UI 工具文件都定义一个 `<NAME>_TOOL` 函数、一个 JSON Schema 常量，并通过 `registry.register(name=..., toolset="desktop_ui", schema=..., handler=lambda args, **kw: ..., emoji=...)` 完成注册。
- 桌面专属工具在未启用 desktop emitter 时统一返回 `tool_error("...only available in the Sparkii desktop app.")`，避免在非 GUI 环境中暴露能力。
- 需要跨进程/渲染器通信的工具通过 `tools.desktop_ui.emit(event, payload)` 发送事件，并以返回值判断是否成功，失败时转为 `tool_error`。
- 终端工具对敏感输出统一使用 `_redact_terminal_error_text` / `agent.redact.redact_sensitive_text` 进行脱敏后再序列化。
- 可选重型依赖（sounddevice、numpy、vercel、modal 等）采用延迟 import 包裹在函数内，确保模块可在无头环境或缺少依赖时正常导入。
- `terminal_hints.py` 中的提示函数均为纯函数 `(command, output) -> Optional[str]`，按生产频率排序并在 `_OUTPUT_HINTS` 列表中顺序匹配，首个命中即返回。
