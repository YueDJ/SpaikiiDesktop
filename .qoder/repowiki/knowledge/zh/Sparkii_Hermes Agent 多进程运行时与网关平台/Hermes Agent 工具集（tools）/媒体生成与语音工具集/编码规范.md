- 所有对外暴露的工具通过 `registry.register(name=..., toolset=..., schema=..., handler=..., check_fn=...)` 声明，handler 返回 JSON 字符串，错误统一走 `tool_error` 或 `error_response`。
- 供应商 SDK 一律采用函数内懒导入（如 `_load_fal_client`、`_import_edge_tts`、`_import_elevenlabs`），避免冷启动开销并在无头环境中安全跳过。
- 配置读取集中在 `_load_*_config()` 中 try/except 包裹 `sparkii_cli.config.load_config()`，失败时回退空字典，保证工具在无配置时仍可工作。
- API Key 通过 `resolve_provider_secret(env_var, provider_id, env_getter=get_env_value)` 统一解析（config > env/.env > 凭证池），禁止在工具内直接读环境变量。
- 对第三方供应商的 payload 构造先合并 model defaults，再应用用户 overrides，最后按 `supports`/`edit_supports` 白名单过滤，确保未知键不会发送到远端。
- 长耗时任务（视频轮询、流式 TTS、命令型 STT）均实现超时与中断检查（`asyncio.wait_for`、`is_interrupted`、`queue.get(timeout)`），避免阻塞整个 agent 循环。
