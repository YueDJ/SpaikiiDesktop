媒体生成与语音工具集封装多供应商后端，通过工具注册表向 Agent 统一暴露。

图像生成（`image_generation_tool.py`，约 1994 行）基于 FAL.ai 平台，维护 `FAL_MODELS` 模型目录（含 FLUX 2 Klein/Pro、Recraft、Ideogram、Qwen 等），每个模型声明尺寸风格族（`image_size_preset`/`aspect_ratio`/`gpt_literal`）、默认参数、`supports` 白名单与是否启用 Clarity Upscaler。`_build_fal_payload()` 将统一输入（prompt + aspect_ratio）翻译为模型特定 payload 并过滤不支持的参数。fal_client 按需懒加载以避免 64ms 的冷启动开销。支持 image-to-image 编辑和多参考图模式。视频生成（`video_generation_tool.py`，约 606 行）采用插件架构，通过 `VideoGenProvider` ABC 和 `video_gen_registry` 动态注册后端，支持 text-to-video、image-to-video 和 reference-to-video 三种模式，参数包括 duration、resolution、aspect_ratio、negative_prompt 等。

TTS 工具（`tts_tool.py`，约 4506 行）内置 10+ 个语音合成提供商：Edge TTS（默认免费）、ElevenLabs（高质量）、OpenAI TTS、MiniMax（支持声音克隆）、Mistral Voxtral、Google Gemini、xAI Grok、NeuTTS/KittenTTS/Piper（本地免费）。用户还可通过 `config.yaml` 的 `tts.providers.<name>` 声明自定义 command 类型提供商。输出格式包括 Opus (.ogg，用于 Telegram 语音气泡) 和 MP3。转录工具（`transcription_tools.py`，约 3017 行）支持 local faster-whisper（默认免费）、Groq Whisper、OpenAI Whisper、Mistral Voxtral、xAI Grok STT、ElevenLabs Scribe 六种后端，被网关自动转录 Telegram/Discord/WhatsApp/Slack/Signal 语音消息。`audio_container.py` 处理音频容器格式转换，`tts_streaming.py` 实现流式 TTS 输出，`tts_text_normalize.py` 提供文本归一化以优化合成质量。
