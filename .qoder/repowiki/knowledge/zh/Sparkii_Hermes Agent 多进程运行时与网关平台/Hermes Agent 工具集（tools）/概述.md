Sparkii Agent 工具集是 Sparkii 系统的执行引擎，以 tools/ 目录为物理载体，提供统一注册、发现与调用的工具生态。该模块的核心是 ToolRegistry 注册表（tools/registry.py），维护所有工具的元数据、Schema 定义、处理器函数与可用性检查。工具发现机制通过 AST 扫描自动检测 tools/*.py 中的 registry.register() 调用，实现模块级自注册，避免手动维护工具列表。

工具集的关键能力包括：声明式 Schema 定义，每个工具通过 JSON Schema 描述参数与返回值，支持动态 Schema 覆盖以适应运行时变化；可用性检查（check_fn）提供 TTL 缓存与瞬态失败宽容，避免外部状态抖动导致工具不可用；工具集分组（toolset）允许按功能域组织工具，支持按需启用特定工具集；错误体截断保护防止单个工具的错误信息撑爆上下文窗口。

工具执行引擎（agent/tool_executor.py）提供并发执行、授权门控、预算控制与增量持久化功能。线程池并行执行工具调用，支持批次级超时与中断信号传播；授权门控序列化人类审批等待，排除在批次截止时间之外；预算控制根据上下文窗口动态计算工具结果预算，防止单次结果撑爆上下文；增量持久化在执行过程中及时落盘，避免破坏性工具导致进程终止而丢失进度。

该模块涵盖丰富的工具类型：浏览器工具（browser_tool.py、browser_cdp_tool.py）支持网页自动化；文件操作工具（file_operations.py、file_tools.py）提供跨终端后端的统一文件读写能力；终端工具（terminal_tool.py）支持代码执行与系统命令；MCP 工具（mcp_tool.py）集成外部服务；技能工具（skills_tool.py）支持动态技能加载；媒体工具支持图像生成、视频生成、语音合成等。所有工具返回 JSON 字符串，确保与模型交互的一致性。
