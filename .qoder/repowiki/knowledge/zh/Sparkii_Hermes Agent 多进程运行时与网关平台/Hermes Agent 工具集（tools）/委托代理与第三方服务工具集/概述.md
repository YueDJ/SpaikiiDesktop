委托代理工具（`delegate_tool.py`，约 4360 行）实现子代理架构，支持单任务与批处理（并行）模式。父 Agent 调用 `delegate_task` 时为每个子代理创建独立的 AIAgent 实例，拥有全新的对话上下文、独立的 task_id（对应独立终端会话和文件操作缓存）、继承父级工具集但屏蔽递归委托和用户交互类工具（`delegate_task`、`clarify`、`memory`、`send_message`、`cronjob` 在 `DELEGATE_BLOCKED_TOOLS` 中被禁止）。子代理的中间工具调用和推理过程不进入父上下文，父级仅接收委托调用和最终摘要结果。

异步委托（`async_delegation.py`，约 1516 行）在模块级守护线程池（`DaemonThreadPoolExecutor`）上运行子代理，立即返回句柄，父 Agent 和用户可继续工作。子代理完成时通过 `process_registry.completion_queue` 推送完成事件，CLI 和 Gateway 在 Agent 空闲时消费该队列并注入新轮次。完成负载包含自包含的任务来源块（目标、上下文、工具集、模型、派发时间、状态、完整结果摘要），确保父代理在不相关上下文中仍能正确使用结果。SQLite 持久化（`state.db`）支持跨重启的崩溃恢复，`_MAX_DELIVERY_ATTEMPTS`（8 次）防止不可路由的记录无限重放。卡住检测通过进度监控线程实现：空闲 450 秒或工具内 1200 秒无进度视为卡住，先中断再给 120 秒宽限期。

第三方服务集成包括 `feishu_doc_tool.py`/`feishu_drive_tool.py`（飞书文档与云盘操作）和 `homeassistant_tool.py`（Home Assistant REST API）。`clarify_tool.py` 提供结构化用户澄清交互，`managed_tool_gateway.py` 管理 Nous 托管工具网关的连接与凭据解析。子代理审批回调通过 `delegation.subagent_auto_approve` 配置，默认自动拒绝危险命令（`_subagent_auto_deny`），避免子代理线程中的 `input()` 调用导致父 TUI 死锁。
