MCP 服务器配置位于 `~/.hermes/config.yaml` 的 `mcp_servers` 键下；OAuth 首次授权需交互式执行 `hermes mcp login <server>`，非交互环境会抛出 `OAuthNonInteractiveError`；可通过 `TOOL_GATEWAY_SCHEME`、`TOOL_GATEWAY_DOMAIN`、`{VENDOR}_GATEWAY_URL`、`TOOL_GATEWAY_USER_TOKEN` 等环境变量覆盖托管网关行为；stdio MCP 子进程 stderr 统一追加到 `SPARKII_HOME/logs/mcp-stderr.log`。
