模块按职责划分为四个子层：
- 连接与工具注册层（`mcp_tool.py`）：在独立 daemon 线程中维护一个 asyncio 事件循环，每个 MCP 服务器以 Task 形式运行，支持 stdio/Streamable HTTP/SSE 三种传输；负责工具列表分页拉取、动态 `tools/list_changed` 通知、采样（sampling）、资源块（图片/音频/文档）缓存为 `MEDIA:` 标记、错误消息脱敏、安全环境变量白名单过滤、OSV 预检超时保护，并通过 `mcp_stdio_watchdog.py` 包装 stdio 子进程实现父进程死亡后的孤儿回收。
- OAuth 授权层（`mcp_oauth.py` + `mcp_dashboard_oauth.py`）：基于 MCP SDK 的 `OAuthClientProvider` 实现浏览器 PKCE 授权码流程；`HermesTokenStorage` 将 token/client_info/metadata 持久化到 `SPARKII_HOME/mcp-tokens/`，使用原子写入（`O_EXCL`+`0o600`）和 mtime 恢复；回调通过本地 `HTTPServer` 或 dashboard 上下文桥接（`DashboardOAuthFlow`）完成；`force_interactive_oauth` / `suppress_interactive_oauth` 用 `ContextVar` 跨线程传播交互性开关。
- OAuth 管理器层（`mcp_oauth_manager.py`）：单例 `MCPOAuthManager` 按 server_name 缓存 `HermesMCPOAuthProvider`（继承自 SDK 的 `OAuthClientProvider`），注入 `_initialize` 预取 PRM/ASM 元数据、`async_auth_flow` 双向生成器桥接、`invalid_client` 自动毒化客户端注册并触发重新注册；提供 mtime 磁盘监听实现外部 cron 刷新 token 的热重载，以及并发 401 去重（同一 access_token 只触发一次恢复）。
- 托管网关层（`managed_tool_gateway.py`）：解析 `TOOL_GATEWAY_*` 环境变量与 `auth.json` 中的 Nous 订阅令牌，构建 `{vendor}-gateway.nousresearch.com` 网关 URL，提供上传 presign→PUT 协议（返回 `nous-upload:<token>` 引用）和受信任网关 URL 校验。
- 辅助层（`mcp_schema_cache.py`）：按 server_name + 配置指纹把工具 schema 持久化到 `cache/mcp_schema_cache.json`，使 dashboard 冷启动无需拉起子进程即可注册工具。
依赖方向单向：`mcp_tool.py` → `mcp_oauth.py` → `mcp_oauth_manager.py` → `mcp_dashboard_oauth.py`；`managed_tool_gateway.py` 独立于 MCP SDK，仅被需要 Nous 托管能力的工具调用。
