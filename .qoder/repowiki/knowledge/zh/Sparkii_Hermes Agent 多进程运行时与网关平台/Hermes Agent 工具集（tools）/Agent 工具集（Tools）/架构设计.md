模块以 `tools/registry.py` 为中心注册表，每个工具文件通过调用 `registry.register(name, toolset, schema, handler, check_fn, emoji)` 将自身暴露给模型；`check_fn` 用于运行时条件启用（如 Home Assistant 需 HASS_TOKEN、Kanban 需 HERMES_KANBAN_TASK 或 profile toolsets）。工具按职责划分为若干子目录：`computer_use/` 封装桌面/浏览器自动化后端，`environments/` 封装沙箱环境（Docker/Modal/Singularity/SSH），其余扁平文件各自对应一类外部系统（memory_tool、session_search_tool、homeassistant_tool、kanban_tools、browser_*、terminal_tool、mcp_*、skills_* 等）。跨工具共享的横切关注点集中在独立文件中：`threat_patterns.py` 统一注入/外泄检测规则，`write_approval.py` 与 `approval.py` 实现写操作审批门控，`ansi_strip.py` 清理 ANSI 转义，`tool_result_storage.py` / `tool_output_limits.py` 管理结果大小与存储。依赖方向单向向外：工具只依赖 `sparkii_state`、`sparkii_cli`、`agent.*`、`utils` 等上层模块，不反向被它们引用。
