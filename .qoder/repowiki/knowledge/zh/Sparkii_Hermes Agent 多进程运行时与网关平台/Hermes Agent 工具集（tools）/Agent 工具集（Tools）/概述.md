Agent 工具集是 Hermes Agent 可被 LLM 直接调用的运行时工具集合，通过统一的注册表机制（`tools/registry.py`）向模型暴露。每个工具模块在导入时声明名称、JSON Schema 与处理函数，运行时由 `model_tools.py` 按会话启用的 toolset 动态组装工具定义列表。

核心工具模块按功能域划分。Web 工具（`web_tools.py`）提供网页搜索与内容提取，支持 Exa、Firecrawl、Parallel、Tavily 等多个搜索后端，可通过 Nous Tool Gateway 托管或直接使用 API Key。消息平台工具包括 `send_message_tool.py`（跨平台消息发送，支持 Telegram、Discord、WhatsApp、Slack 等）和 `discord_tool.py`（Discord 服务器内省与管理，通过 Bot Token 调用 REST API，按 Privileged Intents 动态过滤可用操作）。会话工具 `session_search_tool.py` 提供历史对话的语义搜索与关键词检索能力，`todo_tool.py` 管理轻量级待办事项列表。智能家居工具 `homeassistant_tool.py` 通过 Home Assistant REST API 控制 IoT 设备。Kanban 工具（`kanban_tools.py`）提供任务看板的创建、更新与查询，支持 Agent 内部的任务编排。

记忆工具（`memory_tool.py`）管理持久化的 MEMORY.md 文件，支持追加、搜索与编辑记忆条目。Cron 定时任务工具（`cronjob_tools.py`）提供定时任务的创建、列出、暂停与删除，支持 cron 表达式与间隔两种调度模式。项目工具（`project_tools.py`）提供项目级元数据管理。消息反应工具（`react_to_message_tool.py`）支持对消息添加 emoji 反应。所有工具遵循统一的错误返回格式（`tool_error()` 函数），错误体有 2048 字符上限以防止上下文膨胀。
