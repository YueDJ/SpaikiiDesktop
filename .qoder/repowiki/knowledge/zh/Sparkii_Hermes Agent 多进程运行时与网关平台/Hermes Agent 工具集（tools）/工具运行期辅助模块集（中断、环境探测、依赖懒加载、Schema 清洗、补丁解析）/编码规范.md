- 对外暴露的公共函数以纯函数形式工作，内部可变状态通过模块级锁（`threading.Lock`）或 `ContextVar` 隔离，避免跨线程/跨会话数据泄漏。
- 所有 I/O 与外部命令调用均包裹 try/except 并记录日志，失败时降级为无害返回值而非抛出异常，保证上层工具调用不会被基础设施错误中断。
- 可选功能通过显式 allowlist（如 `LAZY_DEPS`、`_HERMES_PROVIDER_ENV_BLOCKLIST`）+ 运行时检查的方式启用，未注册的特性直接报错而不是隐式尝试。
- 对第三方后端的不兼容输入采取保守修正策略：先 deep copy 再就地修改 schema，仅移除或规范化已知的危险构造，保留语义等价信息（如 `nullable: true`）。
- 解析器统一返回 `(成功结果, 错误消息)` 二元组或带 `success` 字段的 Result dataclass，使调用方能区分空输入与解析错误。
- 通过延迟 import（在函数体内 `from ... import`）打破循环依赖，例如 `patch_parser` 与 `fuzzy_match` 之间互相仅在需要时引用。
