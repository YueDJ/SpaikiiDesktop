本目录是一组相互独立、按职责单一划分的 Python 包，每个文件承担一个横切能力，被上层 tools/ 下的具体工具按需 import：
- `interrupt.py`：基于进程级 `_interrupted_threads: set[int]` + `threading.Lock` 实现 per-thread 中断位，通过 `set_interrupt`/`is_interrupted`/`clear_current_thread_interrupt` 暴露 API，并以 `_ThreadAwareEventProxy` 兼容旧版 `threading.Event` 风格的 `_interrupt_event` 调用点。
- `hook_output_spill.py`：当 hook/plugin 注入的上下文超过 `max_chars` 阈值时，将完整内容写入 `<SPARKII_HOME>/hook_outputs/<session_id>/<uuid>.txt`，返回 head/tail 预览加路径；配置从 `sparkii_cli.config` 的 `hooks.output_spill` 读取，I/O 失败降级为截断提示。
- `env_passthrough.py`：使用 `contextvars.ContextVar` 维护 session-scoped 的环境变量白名单，结合 `tools.environments.local._HERMES_PROVIDER_ENV_BLOCKLIST` 拒绝 Hermes 托管凭据泄露到沙箱子进程，并通过 `resolve_passthrough_value` 在 multiplex secret scope 下解析值。
- `env_probe.py`：启动后在单后台线程中探测本地 Python/pip/PEP-668/uv 状态，结果缓存于进程级变量，系统提示构建时最多等待 `_PROBE_WAIT_TIMEOUT` 秒，超时则 fail-open 不阻塞首 token。
- `lazy_deps.py`：集中声明 `LAZY_DEPS` 特性→pip spec 映射，`ensure()` 在首次导入路径上按需 `uv pip install` 或回退 `python -m pip`/`ensurepip`，支持 durable-target 模式（`HERMES_LAZY_INSTALL_TARGET`）将包追加到 `sys.path` 末尾以避免覆盖核心包，并通过 `security.allow_lazy_installs` 配置开关。
- `schema_sanitizer.py`：对 OpenAI-format tool schema 做深度拷贝并修复 llama.cpp / Anthropic / xAI 等严格后端的已知不兼容形状（bare-string type、anyOf/oneOf null 分支、`$ref` 兄弟关键字、顶层 combinator、属性键非法字符），并提供 `unrename_tool_args` 反向映射。
- `patch_parser.py` + `fuzzy_match.py`：解析 V4A patch 格式为 `PatchOperation` 列表，`apply_v4a_operations` 采用两阶段 validate-then-apply，UPDATE hunk 通过 `fuzzy_match.fuzzy_find_and_replace` 的 9 策略链（exact → line_trimmed → whitespace_normalized → indentation_flexible → escape_normalized → trimmed_boundary → unicode_normalized → block_anchor → context_aware）进行鲁棒匹配与替换，同时处理 MOVE/DELETE/ADD 及 LSP diagnostics 聚合。
依赖方向单向向外：这些模块只依赖标准库、`sparkii_cli.*`、`agent.secret_scope`、`tools.environments.local` 等基础设施，不被其他 tools 反向依赖，从而构成稳定的底层支撑层。
