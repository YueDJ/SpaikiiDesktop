- 所有对外返回结果使用 dataclass 并附带 `to_dict()` 方法，便于 JSON 序列化与模型消费。
- 路径解析统一先展开 `~`、再根据任务上下文（terminal cwd / registered override / `$TERMINAL_CWD`）确定绝对基目录，避免 worktree 场景下的路径漂移。
- 写操作前通过 `agent.file_safety` 的 deny list/prefix 以及 `_check_sensitive_path`、`_protected_instruction_write` 等多层门控拒绝敏感系统路径与受保护指令文件。
- 二进制/大文件识别采用“扩展名快速判断 + 首 N 字节 UTF-8 解码”的两阶段策略，并通过 base64 穿越终端后端避免 mojibake。
- 沙箱子进程环境通过白名单过滤：secret 子串黑名单、安全前缀白名单、精确允许的 `SPARKII_*` 变量，以及 Windows 必需 OS 变量集合。
- 对 git 子进程统一通过 `_run_git`/`_run` 封装，设置 `GIT_CONFIG_GLOBAL/SYSTEM=NUL`、`GIT_CONFIG_NOSYSTEM=1` 以隔离用户 git 配置，并带超时与 allowed_returncodes 处理。
