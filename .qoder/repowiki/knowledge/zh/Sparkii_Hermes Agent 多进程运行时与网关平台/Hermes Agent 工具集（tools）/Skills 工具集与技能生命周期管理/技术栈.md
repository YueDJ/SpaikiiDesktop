Skills Hub CLI 工具链围绕 `sparkii skills` 子命令构建，覆盖技能的全生命周期管理。核心依赖包括：Python 标准库 `ast` 模块用于 AST 级深度审计（`skills_ast_audit.py`），检测 `importlib.import_module()`、动态 `getattr`、`__dict__[computed]` 等动态代码模式；`httpx` 作为异步 HTTP 客户端与 GitHub API 交互；`PyYAML` 解析 SKILL.md 的 YAML frontmatter；`PyJWT` + `cryptography` 实现 GitHub App RS256 JWT 签名认证。

使用分析与追踪依赖 `fcntl`（POSIX）/ `msvcrt`（Windows）的文件锁机制保护 `.usage.json` 并发写入，记录每个技能的最后访问时间与使用次数。`skills_guard.py`（1161 行）提供内容哈希与安全扫描，通过 `ScanResult` 数据类报告扫描结果，`TRUSTED_REPOS` 白名单免检已知安全仓库的技能。`skills_sync.py`（1411 行）实现 manifest 驱动的技能同步客户端，使用 MD5 哈希跟踪打包技能的来源状态，支持增量更新（新技能复制、已修改但未定制的技能更新、用户定制的技能跳过、已删除技能清理）。`skills_sync_client.py`（2187 行）扩展为 Hub 级同步，处理远程索引的拉取与本地缓存。

Provenance 跟踪通过 `HubLockFile`（JSON 格式）记录每个已安装 Hub 技能的来源仓库、路径、版本哈希与安装时间戳。`HubAuditLog` 以追加模式记录安装、更新、卸载等操作。`quarantine` 目录隔离待安全扫描的新安装技能，扫描通过后才移入正式目录。这些机制确保第三方技能的来源可追溯、变更可审计。
