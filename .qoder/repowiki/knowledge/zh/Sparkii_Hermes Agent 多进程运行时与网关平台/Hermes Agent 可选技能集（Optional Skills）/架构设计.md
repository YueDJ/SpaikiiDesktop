模块按领域划分目录（blockchain、creative、data-science、devops、finance、gaming、health、mcp、migration、mlops、payments、productivity、research、security、software-development、web-development 等），每个子领域下再按具体技能分目录，每个技能目录遵循统一结构：SKILL.md（YAML frontmatter + Markdown 说明）、可选 scripts/（Python/Shell/JS 工具脚本）、references/（参考文档）、templates/（模板文件）。SKILL.md 中的 YAML frontmatter 声明 name/description/version/author/license/platforms 以及 hermes.metadata（tags、category、related_skills、requires_toolsets），供 `hermes skills browse/search/install` 索引与发现。技能通过 `~/.hermes/skills/<domain>/<skill>/scripts/*` 暴露可执行脚本，由 SKILL.md 中的命令示例调用；部分技能还包含 PORT_NOTES.md、TROUBLESHOOTING.md、requirements.txt 等辅助文件。顶层 DESCRIPTION.md 说明这些技能为“非默认激活”，需用户主动通过 CLI 安装。
