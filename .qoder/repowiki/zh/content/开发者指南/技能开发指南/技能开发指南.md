### Frontmatter解析

系统通过parse_frontmatter()解析YAML frontmatter：

`python
def parse_frontmatter(content: str) -> tuple[dict, str]:
    """解析SKILL.md的frontmatter"""
    # 处理BOM标记
    if content.startswith('\ufeff'):
        content = content[1:]
    
    # 分割frontmatter和内容
    parts = content.split('---', 2)
    if len(parts) >= 3:
        metadata = yaml.safe_load(parts[1])
        body = parts[2].strip()
        return metadata, body
    
    return {}, content
`

## 技能包（Bundles）

### 技能包结构

技能包通过YAML文件定义多个技能：

`yaml
name: my-bundle
description: 我的技能包
skills:
  - name: skill1
    description: 技能1描述
  - name: skill2
    description: 技能2描述
instruction: |
  这是技能包的总体指令...
`

### 技能包加载

系统通过skill_bundles.py加载技能包：

`python
def scan_bundles() -> list[dict]:
    """扫描技能包目录"""
    bundles = []
    bundle_dir = os.path.expanduser("~/.sparkii/skill-bundles")
    
    for filename in os.listdir(bundle_dir):
        if filename.endswith('.yaml'):
            filepath = os.path.join(bundle_dir, filename)
            with open(filepath, 'r', encoding='utf-8') as f:
                bundle = yaml.safe_load(f)
                bundles.append(bundle)
    
    return bundles
`

### 冲突解决

当技能包与独立技能同名时的处理：

`python
def resolve_conflicts(skills: list, bundles: list) -> list:
    """解决技能名冲突"""
    # 技能包优先于独立技能
    bundle_names = {b['name'] for b in bundles}
    return [s for s in skills if s['name'] not in bundle_names] + bundles
`

### 版本管理

`python
class SkillVersion:
    MAJOR = "major"  # 不兼容的API变更
    MINOR = "minor"  # 向后兼容的功能新增
    PATCH = "patch"  # 向后兼容的问题修复
    
    @staticmethod
    def bump(version: str, level: str) -> str:
        major, minor, patch = map(int, version.split('.'))
        if level == SkillVersion.MAJOR:
            return f"{major + 1}.0.0"
        elif level == SkillVersion.MINOR:
            return f"{major}.{minor + 1}.0"
        else:
            return f"{major}.{minor}.{patch + 1}"
`
