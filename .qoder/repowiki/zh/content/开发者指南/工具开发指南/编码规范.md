## 简介
本文档制定统一的代码规范和命名约定，确保代码库的一致性和可维护性。涵盖Python和TypeScript/JavaScript两种主要语言的编码标准。

## Python代码规范

### PEP 8标准遵循
- **行长度**：每行不超过88字符(Black默认)
- **缩进**：使用4个空格
- **空行**：函数间空2行，类内方法间空1行

### 命名规则
| 类型 | 规范 | 示例 |
|------|------|------|
| 变量 | snake_case | user_name, max_retries |
| 函数 | snake_case | get_user_data(), validate_input() |
| 类 | PascalCase | ToolRegistry, MemoryProvider |
| 常量 | UPPER_SNAKE_CASE | MAX_TIMEOUT, DEFAULT_PORT |
| 私有 | _前缀 | _internal_helper() |

### 模块组织
```python
# 1. 标准库导入
import os
import sys

# 2. 第三方库导入
import requests
from pydantic import BaseModel

# 3. 本地模块导入
from .config import settings
from .utils import helper
```

## TypeScript/JavaScript规范

### ESLint配置
```json
{
  "extends": ["eslint:recommended", "plugin:@typescript-eslint/recommended"],
  "rules": {
    "@typescript-eslint/no-explicit-any": "warn",
    "@typescript-eslint/explicit-function-return-type": "error"
  }
}
```

### 命名约定
- **变量/函数**：camelCase
- **类/接口/类型**：PascalCase
- **常量**：UPPER_SNAKE_CASE
- **文件名**：kebab-case

## 注释规范

### 文档字符串格式
```python
def process_data(data: dict, timeout: int = 30) -> dict:
    """处理输入数据并返回结果。

    Args:
        data: 输入数据字典，包含必要字段
        timeout: 超时时间(秒)，默认30秒

    Returns:
        处理结果字典，包含success和result字段

    Raises:
        ValueError: 当输入数据格式不正确时
        TimeoutError: 当处理超时时
    """
```

### 代码内注释
- 解释**为什么**这样做，而不是**做什么`
- 避免显而易见的注释
- 复杂逻辑必须添加注释说明
