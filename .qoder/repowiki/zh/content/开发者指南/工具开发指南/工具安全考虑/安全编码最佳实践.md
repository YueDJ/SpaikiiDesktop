## SQL注入防护

### 参数化查询
```python
# 错误方式
query = f"SELECT * FROM users WHERE id = {user_id}"

# 正确方式
cursor.execute("SELECT * FROM users WHERE id = ?", (user_id,))
```

### ORM框架使用
```python
from sqlalchemy import text

# 使用ORM查询
users = session.query(User).filter(User.id == user_id).all()

# 使用参数化文本查询
result = session.execute(
    text("SELECT * FROM users WHERE id = :id"),
    {"id": user_id}
)
```

## 路径遍历防护

### 路径规范化
```python
from pathlib import Path

def safe_path(user_path, allowed_root):
    # 规范化路径
    resolved = Path(user_path).resolve()
    root = Path(allowed_root).resolve()
    
    # 检查是否在允许范围内
    try:
        resolved.relative_to(root)
    except ValueError:
        raise PermissionError("Path traversal detected")
    
    return resolved
```

### 访问控制检查
```python
def check_access(path, mode):
    if mode == 'write':
        if not path.parent.exists():
            raise FileNotFoundError("Parent directory not found")
        if os.path.ismount(path):
            raise PermissionError("Cannot write to mount point")
```

### 哈希算法选择
```python
import hashlib

# 使用SHA-256
def hash_data(data):
    return hashlib.sha256(data.encode()).hexdigest()

# 使用bcrypt处理密码
import bcrypt

def hash_password(password):
    return bcrypt.hashpw(password.encode(), bcrypt.gensalt())
```
