## 简介

Sparkii Agent的工具集打包系统为开发者提供了一套标准化的工具组织和分发框架。工具集(Toolset)是相关工具的逻辑分组，通过统一的目录结构和元数据定义，实现工具的发现、加载和管理。本文档详细说明工具集的打包规范，帮助开发者创建符合标准的工具集包。

## 工具集目录结构

标准的工具集目录结构如下：

`
toolset-name/
├── __init__.py          # 工具集初始化入口
├── tools/               # 工具实现文件
│   ├── tool_a.py
│   └── tool_b.py
├── SKILL.md             # 技能描述文件（可选）
├── manifest.json        # 工具集元数据清单
├── requirements.txt     # Python依赖声明
└── README.md            # 使用说明文档
`

### manifest.json格式

manifest.json是工具集的核心元数据文件，定义了工具集的基本信息和依赖关系：

`json
{
  name: my-toolset,
  version: 1.0.0,
  description: 自定义工具集示例,
  author: Developer Name,
  toolset_category: custom,
  tools: [
    {
      name: tool_a,
      description: 工具A的功能描述,
      schema: {...}
    }
  ],
  dependencies: {
    python: >=3.11,
    packages: [requests>=2.28.0]
  },
  entry_point: __init__.py
}
`

## Skill Bundles打包标准

技能包(Skill Bundle)是将多个工具组合成完整解决方案的打包方式。技能包通过SKILL.md文件定义工具的使用说明和触发条件。

### SKILL.md编写规范

`markdown
---
name: my-skill
description: 技能的简短描述（建议60字符以内）
---

# 技能名称

## 触发条件
当用户需要...时使用此技能。

## 使用步骤
1. 第一步操作说明
2. 第二步操作说明
3. ...

## 注意事项
- 注意事项1
- 注意事项2
`

### 版本管理策略

工具集采用语义化版本控制(SemVer)：
- **主版本号**：不兼容的API变更
- **次版本号**：向下兼容的功能新增
- **修订号**：向下兼容的问题修正

## 工具集分类体系

Sparkii Agent的工具集分为以下类别：

| 类别 | 说明 | 示例 |
|------|------|------|
| **官方工具集** | 核心团队维护的内置工具 | terminal, file, web, browser |
| **社区工具集** | 社区贡献的第三方工具 | 数据分析、AI图像处理 |
| **自定义工具集** | 用户自行开发的工具 | 企业内部系统集成 |

## 工具集分发机制

工具集通过以下方式分发：

1. **内置分发**：核心工具集随Sparkii Agent一起安装
2. **Hub安装**：通过sparkii skills install <name>从Hub仓库安装
3. **本地加载**：从~/.sparkii/skills/目录自动发现

## 安全验证与签名

工具集的安全验证包括：

1. **代码签名验证**：验证工具集的数字签名确保完整性
2. **OSV恶意软件检查**：启动时扫描已知漏洞和恶意代码
3. **权限控制**：工具集声明所需权限，由用户授权

`python
# 工具注册时的安全检查示例
registry.register(
    name=my_tool,
    toolset=custom,
    schema=TOOL_SCHEMA,
    handler=my_handler,
    check_fn=lambda: check_environment(),  # 环境检查
    requires_env=[API_KEY],              # 所需环境变量
)
`

## 最佳实践

### 打包建议

1. **单一职责**：每个工具集专注于一类功能
2. **清晰文档**：提供完整的README和SKILL.md
3. **依赖最小化**：只声明必要的依赖项
4. **错误处理**：所有工具必须返回标准的JSON错误格式
