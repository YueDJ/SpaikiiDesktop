## 日志格式规范

### 结构化日志
`json
{
  "timestamp": "2024-01-15T10:30:00.123Z",
  "level": "INFO",
  "logger": "agent.conversation_loop",
  "message": "User message processed",
  "session_id": "sess_123",
  "user_id": "user_456",
  "duration_ms": 150,
  "tool_calls": 2,
  "tokens_used": 500
}
`

### 字段定义
| 字段 | 类型 | 说明 |
|------|------|------|
| timestamp | ISO 8601 | 时间戳 |
| level | string | 日志级别 |
| logger | string | 日志记录器名称 |
| message | string | 日志消息 |
| session_id | string | 会话 ID |
| user_id | string | 用户 ID |

## 日志采集配置

### 文件日志采集
`yaml
logging:
  handlers:
    - type: "file"
      path: "~/.sparkii/logs/agent.log"
      max_size: "50MB"
      backup_count: 10
      format: "json"
    - type: "console"
      level: "INFO"
      format: "text"
`

### 系统日志采集
`yaml
logging:
  syslog:
    enabled: true
    host: "localhost"
    port: 514
    facility: "local0"
`

## 日志查询与过滤

### 命令行查询
`ash
# 按级别过滤
sparkii logs --level ERROR

# 按时间范围
sparkii logs --from "2024-01-15" --to "2024-01-16"

# 按会话 ID
sparkii logs --session-id sess_123

# 全文搜索
sparkii logs --search "timeout"
`

### 查询语法
`sql
-- SQL-like 查询语法
SELECT * FROM logs
WHERE level = 'ERROR'
AND timestamp > '2024-01-15'
AND message LIKE '%timeout%'
ORDER BY timestamp DESC
LIMIT 100
`
