## 简介
本文档详细说明Sparkii Agent记忆系统的数据模型设计。系统通过memory_manager.py和memory_provider.py定义了完整的记忆数据结构，支持短期记忆、长期记忆、语义索引和用户画像等多种记忆类型。

## 记忆类型定义

### 短期记忆

短期记忆存储当前会话的临时信息：

`python
@dataclass
class ShortTermMemory:
    session_id: str
    turn_count: int
    context_window: list[Message]
    working_memory: dict[str, Any]
    created_at: datetime
    expires_at: datetime
`

### 长期记忆

长期记忆存储持久化的知识和结论：

`python
@dataclass
class LongTermMemory:
    id: str
    content: str
    memory_type: MemoryType  # KNOWLEDGE, CONCLUSION, PREFERENCE
    source: str
    confidence: float
    created_at: datetime
    accessed_at: datetime
    access_count: int
    metadata: dict[str, Any]
`

### 语义索引

语义索引支持向量检索：

`python
@dataclass
class SemanticIndex:
    id: str
    content: str
    embedding: list[float]
    memory_id: str
    created_at: datetime
`

### 用户画像

用户画像存储用户特征和偏好：

`python
@dataclass
class UserProfile:
    user_id: str
    card: str  # 短小精悍的事实清单
    representation: str  # 更丰富的用户画像
    preferences: dict[str, Any]
    interaction_history: list[dict]
    updated_at: datetime
`

## 数据关联与索引

### 关联关系

`mermaid
erDiagram
    LONG_TERM_MEMORY ||--o{ SEMANTIC_INDEX : has
    USER_PROFILE ||--o{ LONG_TERM_MEMORY : contains
    SHORT_TERM_MEMORY ||--o{ LONG_TERM_MEMORY : derives
    SEMANTIC_INDEX }|--|| LONG_TERM_MEMORY : references
`

### 索引策略

1. **时间索引**: 按创建时间排序，支持时间范围查询
2. **语义索引**: 向量相似度检索，支持语义搜索
3. **关系索引**: 实体关系图，支持关联查询

### 查询优化

`python
class MemoryQuery:
    def __init__(self):
        self.semantic_weight = 0.7
        self.temporal_weight = 0.2
        self.relevance_weight = 0.1
    
    def query(self, text: str, limit: int = 10) -> list[LongTermMemory]:
        # 混合检索策略
        semantic_results = self._semantic_search(text, limit * 2)
        temporal_results = self._temporal_search(limit)
        
        # 结果融合和排序
        return self._merge_results(semantic_results, temporal_results, limit)
`
