## 相似性检测

### 语义相似度计算

使用向量嵌入计算语义相似度：

`python
def calculate_semantic_similarity(text1: str, text2: str) -> float:
    """计算语义相似度"""
    # 获取嵌入向量
    embedding1 = get_embedding(text1)
    embedding2 = get_embedding(text2)
    
    # 计算余弦相似度
    similarity = cosine_similarity(embedding1, embedding2)
    return similarity
`

### 去重阈值

系统设置相似度阈值进行去重：

`python
DEDUP_THRESHOLD = 0.85  # 85%相似度认为重复

def is_duplicate(memory1: dict, memory2: dict) -> bool:
    """判断是否重复"""
    similarity = calculate_semantic_similarity(
        memory1["content"],
        memory2["content"]
    )
    return similarity >= DEDUP_THRESHOLD
`

### 批量去重

`python
def batch_dedup(memories: list[dict]) -> list[dict]:
    """批量去重"""
    unique_memories = []
    seen_embeddings = []
    
    for memory in memories:
        embedding = get_embedding(memory["content"])
        
        # 检查是否与已有记忆重复
        is_dup = False
        for seen_emb in seen_embeddings:
            if cosine_similarity(embedding, seen_emb) >= DEDUP_THRESHOLD:
                is_dup = True
                break
        
        if not is_dup:
            unique_memories.append(memory)
            seen_embeddings.append(embedding)
    
    return unique_memories
`

### 冲突解决

当记忆内容冲突时的处理策略：

`python
def resolve_conflicts(memories: list[dict]) -> dict:
    """解决记忆冲突"""
    # 按时间排序（最新的优先）
    sorted_memories = sorted(
        memories,
        key=lambda m: m["created_at"],
        reverse=True
    )
    
    # 保留最新且置信度最高的
    for memory in sorted_memories:
        if memory["confidence"] >= 0.8:
            return memory
    
    # 否则合并但标记冲突
    return {
        "content": "存在冲突信息，请谨慎使用",
        "conflicts": [m["id"] for m in memories]
    }
`

class OptimizedIndex:
    def __init__(self):
        self.vector_index = None  # 向量索引
        self.keyword_index = {}  # 关键词索引
        self.time_index = []  # 时间索引
    
    def build_index(self, memories: list[dict]):
        """构建优化索引"""
        # 构建向量索引
        embeddings = [get_embedding(m["content"]) for m in memories]
        self.vector_index = build_faiss_index(embeddings)
        
        # 构建关键词倒排索引
        for memory in memories:
            keywords = extract_keywords(memory["content"])
            for keyword in keywords:
                if keyword not in self.keyword_index:
                    self.keyword_index[keyword] = []
                self.keyword_index[keyword].append(memory["id"])
        
        # 构建时间索引
        self.time_index = sorted(memories, key=lambda m: m["created_at"])
`

### 缓存策略

`python
class MemoryCache:
    def __init__(self, max_size=1000):
        self.cache = OrderedDict()
        self.max_size = max_size
    
    def get(self, key: str) -> dict | None:
        if key in self.cache:
            # 移到最近使用
            self.cache.move_to_end(key)
            return self.cache[key]
        return None
    
    def put(self, key: str, value: dict):
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.max_size:
            self.cache.popitem(last=False)
`

## 最佳实践

### 压缩率与准确性平衡

1. **保守压缩**: 对于重要信息，宁可保留冗余
2. **渐进压缩**: 先压缩低置信度记忆
3. **可逆压缩**: 保留原始数据的备份

### 性能监控

`python
class CompressionMetrics:
    def __init__(self):
        self.original_size = 0
        self.compressed_size = 0
        self.compression_ratio = 0.0
        self.dedup_count = 0
        self.merge_count = 0
    
    def calculate_ratio(self):
        if self.original_size > 0:
            self.compression_ratio = 1 - (self.compressed_size / self.original_size)
`

### 故障排除

1. **压缩失败**: 检查输入数据格式
2. **去重过度**: 调整DEDUP_THRESHOLD参数
3. **合并冲突**: 检查冲突解决策略
4. **性能下降**: 优化索引结构
