## 简介

Sparkii Agent支持多种AI模型提供商，通过插件化架构实现灵活的模型切换。本文档详细说明各主要提供商的连接配置方法、API密钥管理、请求限制设置和高级特性配置。

## 提供商配置架构

## OpenAI配置

### 基础配置

`yaml
# config.yaml
providers:
  openai:
    api_key: " # 从环境变量读取
 base_url: https://api.openai.com/v1 # 可选，自定义端点
 organization:  # 可选
 timeout: 120 # 请求超时（秒）
 max_retries: 3 # 最大重试次数
`

### 高级特性

`yaml
providers:
 openai:
 # 流式响应配置
 stream: true
 
 # 工具调用配置
 tool_choice: auto # auto, none, required
 
 # Vision支持
 vision:
 enabled: true
 max_image_size: 20MB
 
 # 音频配置
 audio:
 voice: alloy
 speed: 1.0
`

### API密钥获取

1. 访问[OpenAI Platform](https://platform.openai.com)
2. 导航到API Keys页面
3. 创建新的Secret Key
4. 复制到.env文件：OPENAI_API_KEY=sk-...

## Anthropic配置

### 基础配置

`yaml

## AWS Bedrock配置

providers:

## 高级特性配置

### 流式响应

所有提供商统一支持流式响应配置：

`yaml
providers:
 openai:
 stream: true
 stream_options:
 include_usage: true # 包含token使用统计
`

### 并发控制

`yaml
providers:
 openai:
 # 并发请求限制
 max_concurrent_requests: 10
 
 # 请求队列配置
 queue:
 max_size: 100
 timeout: 30
`

### 成本控制

`yaml
providers:
 openai:
 # Token预算限制
 budget:
 daily_limit: 1000000 # 每日token限制
 monthly_limit: 30000000 # 每月限制
 alert_threshold: 0.8 # 80%时告警
`

## 故障排除

### 连接测试

`ash
# 测试OpenAI连接
sparkii model test openai

# 测试所有提供商
sparkii model test --all
`

### 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 401 Unauthorized | API密钥无效 | 检查.env中的密钥 |
| 429 Too Many Requests | 请求频率超限 | 降低并发或增加延迟 |
| 500 Server Error | 提供商服务故障 | 稍后重试或切换提供商 |
| Timeout | 网络问题或超时设置过短 | 增加timeout配置 |
