## 请求参数
`json
{
  "prompt": "A beautiful sunset over the ocean",
  "model": "dall-e-3",
  "size": "1024x1024",
  "quality": "standard",
  "style": "vivid",
  "n": 1,
  "response_format": "url"
}
`

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| prompt | string | 是 | 图像描述提示词 |
| model | string | 否 | 模型名称，默认 dall-e-3 |
| size | string | 否 | 图像尺寸 |
| quality | string | 否 | 质量等级 |
| n | integer | 否 | 生成数量 |

## 支持的模型

### DALL-E 3
- 高质量图像生成
- 支持 1024x1024, 1024x1792, 1792x1024 尺寸
- 支持 standard 和 hd 质量

### Stable Diffusion
- 开源模型，支持自定义
- 多种尺寸和风格选项
- 本地或云端部署

### FAL AI
- 快速生成
- 多种预训练模型
- API 调用简单

`mermaid
graph LR
    API["图像生成 API"] --> DALL-E["DALL-E 3"]
    API --> SD["Stable Diffusion"]
    API --> FAL["FAL AI"]
    DALL-E --> OpenAI["OpenAI 服务"]
    SD --> Local["本地部署"]
    FAL --> FALCloud["FAL 云服务"]
`

## 异步生成
对于耗时较长的生成任务，支持异步模式：

`python
# 异步生成
response = await client.images.generate(
    prompt="complex scene",
    async_mode=True
)
# 轮询状态
while response.status != "completed":
    await asyncio.sleep(1)
    response = await client.get_generation(response.id)
`

## 安全与过滤
- 内容审核：自动过滤违规内容
- NSFW 检测：识别不当图像
- 版权保护：避免生成受版权保护的内容
- 速率限制：防止滥用

## 故障排查指南
- **生成失败**: 检查 API 密钥和配额
- **质量不佳**: 优化提示词描述
- **超时**: 调整超时配置或使用异步模式
