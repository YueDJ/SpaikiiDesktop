## 简介
描述消息格式转换的详细设计文档。说明 OpenAI 格式消息与不同提供商原生格式的转换机制，包括系统消息处理、用户/助手对话轮次转换、多模态消息支持。详细说明 convert_messages 函数的实现策略，包括消息结构映射、元数据保留和非标准消息处理。提供 Anthropic Messages API 和 Chat Completions API 的具体转换示例。说明未知/不支持消息类型、图片、视频、文件等的处理。说明消息验证策略和使用最佳实践。描述不同提供商的消息格式差异和资源消耗对比。

## OpenAI 格式
### 消息结构
`json
{
  "role": "user",
  "content": [
    {"type": "text", "text": "Hello"},
    {"type": "image_url", "image_url": {"url": "data:image/png;base64,..."}}
  ]
}
`

### 角色映射
| 内部角色 | OpenAI 角色 | 说明 |
|---------|------------|------|
| user | user | 用户消息 |
| assistant | assistant | 助手消息 |
| tool | tool | 工具结果 |
| system | system | 系统提示 |

## Anthropic 格式
### 消息结构
`json
{
  "role": "user",
  "content": [
    {"type": "text", "text": "Hello"},
    {"type": "image", "source": {"type": "base64", "media_type": "image/png", "data": "..."}}
  ]
}
`

### 关键差异
- 图像格式：Anthropic 使用 source 对象，OpenAI 使用 image_url
- 系统消息：Anthropic 使用独立的 system 参数
- 工具调用：格式略有不同

## 系统消息处理
系统消息在转换过程中需要特殊处理：
- 多条系统消息合并为一条
- 系统消息位置调整（Anthropic 要求在最前面）
- 系统消息中的特殊指令保留
