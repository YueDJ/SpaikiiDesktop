## 简介
本文档详细说明MCP（Model Context Protocol）支持的三种传输方式：STDIO、HTTP/StreamableHTTP和SSE。每种传输方式适用于不同的使用场景，提供不同的性能和可靠性特征。

## 传输协议架构

传输层抽象提供统一的接口：
- **connect()**: 建立连接
- **send()**: 发送消息
- **receive()**: 接收消息
- **close()**: 关闭连接

## STDIO传输

### 特点

- **延迟**: 极低（本地进程间通信）
- **吞吐量**: 高（管道通信）
- **可靠性**: 高（无网络问题）
- **适用场景**: 本地MCP服务器

### 配置示例

`yaml
mcp_servers:
  local_server:
    transport: stdio
    command: "node"
    args: ["server.js"]
    env:
      NODE_ENV: "production"
`

C->>P: 关闭连接

## HTTP/StreamableHTTP传输

### 特点

- **延迟**: 中等（网络往返）
- **吞吐量**: 中等（HTTP连接限制）
- **可靠性**: 中等（受网络影响）
- **适用场景**: 远程MCP服务器、云服务

### 配置示例

`yaml
mcp_servers:
  remote_server:
    transport: http
    url: "https://mcp.example.com"
    headers:
      Authorization: "Bearer "
    timeout: 30

## SSE传输

### 特点

- **延迟**: 低（服务器推送）
- **吞吐量**: 高（长连接）
- **可靠性**: 中等（需要重连机制）
- **适用场景**: 实时更新、流式响应

### 配置示例

`yaml
mcp_servers:
  realtime_server:
    transport: sse
    url: "https://mcp.example.com/sse"
    headers:
      Authorization: "Bearer "
    reconnect_interval: 5
`

### 工作流程

## 传输协议对比

| 特性 | STDIO | HTTP | SSE |
|------|-------|------|-----|
| **延迟** | 极低 | 中等 | 低 |
| **吞吐量** | 高 | 中等 | 高 |
| **可靠性** | 高 | 中等 | 中等 |
| **网络依赖** | 无 | 有 | 有 |
| **适用场景** | 本地服务器 | 远程服务 | 实时更新 |
| **配置复杂度** | 低 | 中 | 中 |
| **安全性** | 高（本地） | 中（HTTPS） | 中（HTTPS） |

### 选择建议

1. **本地开发**: 使用STDIO传输
2. **云服务**: 使用HTTP传输
3. **实时应用**: 使用SSE传输
4. **混合场景**: 根据需求选择

## 连接管理

### 连接池

`python
class TransportPool:
    """传输连接池"""
    
    def __init__(self, max_connections=10):
        self.pool = {}
        self.max_connections = max_connections
    
    def get_connection(self, config: dict):
        key = self._make_key(config)
        if key not in self.pool:
            self.pool[key] = self._create_connection(config)
        return self.pool[key]
`

### 自动重连

`python
async def reconnect_with_backoff(transport, max_retries=5):
    """带退避的自动重连"""
    for attempt in range(max_retries):
        try:
            await transport.connect()
            return True
        except Exception as e:
            delay = min(2 ** attempt, 30)
            await asyncio.sleep(delay)
    return False
`

### 心跳检测

`python
async def heartbeat_loop(transport, interval=30):
    """心跳检测循环"""
    while True:
        await asyncio.sleep(interval)
        try:
            await transport.ping()
        except Exception:
            await transport.reconnect()
`
