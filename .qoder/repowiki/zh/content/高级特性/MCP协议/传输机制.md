## STDIO 传输
STDIO 传输通过标准输入/输出进行进程间通信：

`python
# STDIO 传输实现
class StdioTransport:
    def __init__(self, command, args):
        self.process = subprocess.Popen(
            [command] + args,
            stdin=subprocess.PIPE,
            stdout=subprocess.PIPE,
            stderr=subprocess.PIPE
        )

    async def send_request(self, request):
        self.process.stdin.write(json.dumps(request).encode())
        self.process.stdin.flush()
        response = self.process.stdout.readline()
        return json.loads(response)
`

## HTTP/StreamableHTTP 传输
HTTP 传输使用标准 HTTP 协议进行通信：

`yaml
mcp:
  servers:
    - name: "remote-tools"
      transport: "http"
      url: "http://localhost:8080/mcp"
      headers:
        Authorization: "Bearer token123"
`

### StreamableHTTP 特性
- 支持流式响应
- 长连接保持
- 自动重连机制

## SSE 传输
SSE（Server-Sent Events）传输提供服务器到客户端的单向推送：

`python
# SSE 事件流处理
async def handle_sse(response):
    async for line in response.content:
        if line.startswith(b'data: '):
            event = json.loads(line[6:])
            yield event
`

## 传输选择策略
选择传输方式时考虑以下因素：
- **本地 vs 远程**: 本地工具使用 STDIO，远程服务使用 HTTP/SSE
- **延迟要求**: 低延迟场景优先 STDIO 或 SSE
- **可靠性**: HTTP 提供最可靠的请求-响应模式
- **扩展性**: HTTP/SSE 支持分布式部署

## 故障排查指南
- **连接拒绝**: 检查服务端是否启动
- **超时**: 调整 timeout 配置
- **消息丢失**: 检查网络连接和缓冲区大小
