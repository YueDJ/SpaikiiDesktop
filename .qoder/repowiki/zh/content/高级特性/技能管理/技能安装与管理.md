## 技能安装方式

### 本地安装
`ash
# 从本地目录安装
sparkii skills install ./my-skill/

# 从压缩包安装
sparkii skills install my-skill.zip
`

### 自动下载
`ash
# 从技能市场安装
sparkii skills install @sparkii/web-scraper

# 指定版本
sparkii skills install @sparkii/web-scraper@1.2.0
`

### Git 仓库克隆
`ash
# 从 Git 仓库安装
sparkii skills install git+https://github.com/user/skill.git

# 私有仓库（需要认证）
sparkii skills install git+https://github.com/user/private-skill.git --token YOUR_TOKEN
`

## 技能管理功能

### 技能列表
`ash
# 查看已安装技能
sparkii skills list

# 查看可用技能
sparkii skills search web
`

### 版本控制
`ash
# 查看技能版本
sparkii skills info @sparkii/web-scraper

# 更新技能
sparkii skills update @sparkii/web-scraper

# 回滚到指定版本
sparkii skills rollback @sparkii/web-scraper@1.0.0
`

### 禁用/启用
`ash
# 禁用技能
sparkii skills disable @sparkii/web-scraper

# 启用技能
sparkii skills enable @sparkii/web-scraper
`
