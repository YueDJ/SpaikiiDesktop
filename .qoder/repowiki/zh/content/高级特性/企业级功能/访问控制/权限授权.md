## RBAC 模型

`mermaid
graph TB
    User["用户"] --> Role["角色"]
    Role --> Permission["权限"]
    Permission --> Resource["资源"]
    Role --> Inherits["角色继承"]
    Inherits --> ChildRole["子角色"]
    ChildRole --> Permission
`

### 角色层次
- **admin**: 完全控制权限
- **developer**: 开发和调试权限
- **user**: 基本使用权限
- **viewer**: 只读权限

### 权限继承
`yaml
roles:
  admin:
    inherits: [developer]
    permissions: ["*"]
  developer:
    inherits: [user]
    permissions: ["tools.*", "sessions.*", "config.read"]
  user:
    permissions: ["chat.*", "sessions.own"]
`

## ABAC 实现
基于属性的访问控制支持更细粒度的权限管理：

### 属性类型
- **用户属性**: role, department, clearance_level
- **资源属性**: owner, sensitivity, classification
- **环境属性**: time, location, network

### 策略示例
`yaml
policies:
  - name: "sensitive-data-access"
    effect: "allow"
    conditions:
      - user.clearance_level >= resource.sensitivity
      - time.hour >= 9 and time.hour <= 17
      - network.type == "internal"
`

## 动态权限验证
`python
class PermissionChecker:
    async def check(self, user, resource, action, context):
        # 1. 检查静态角色权限
        if self.check_role_permission(user.role, resource, action):
            return True
        # 2. 检查 ABAC 策略
        if await self.check_abac_policy(user, resource, action, context):
            return True
        # 3. 检查临时权限
        if await self.check_temporary_permission(user, resource, action):
            return True
        return False
`

## 权限配置
### YAML 配置
`yaml
authorization:
  enabled: true
  default_role: "user"
  roles_file: "roles.yaml"
  policies_file: "policies.yaml"
  cache_ttl: 300
`

### 环境变量
`ash
export AUTHZ_ENABLED=true
export AUTHZ_DEFAULT_ROLE=user
export AUTHZ_CACHE_TTL=300
`
