## 指数退避算法

### jittered_backoff函数

系统使用带抖动的指数退避算法避免惊群效应：

`python
def jittered_backoff(
    attempt: int,
    base_delay: float = 1.0,
    max_delay: float = 60.0,
    jitter_factor: float = 0.5
) -> float:
    """计算带抖动的退避时间"""
    # 指数增长
    delay = min(base_delay * (2 ** attempt), max_delay)
    # 添加随机抖动
    jitter = delay * jitter_factor * (2 * random.random() - 1)
    return max(0, delay + jitter)
`

### 算法特点

1. **指数增长**: 延迟时间按指数增长，避免频繁重试
2. **最大延迟限制**: 设置上限防止延迟过长
3. **随机抖动**: 添加随机性避免惊群效应
4. **种子多样性**: 使用time_ns + 计数器确保每次运行不同

### 退避时间示例

| 0 | 1s | ±0.5s | 0.5-1.5s |

## 超时控制

### Retry-After头解析

系统支持解析HTTP Retry-After头：

`python
def parse_retry_after_seconds(response) -> float | None:
    """解析Retry-After头"""
    retry_after = response.headers.get('Retry-After')
    if not retry_after:
        return None
    
    # 数字格式（秒）
    if retry_after.isdigit():
        return float(retry_after)
    
    # HTTP-date格式
    try:
        retry_date = datetime.strptime(retry_after, '%a, %d %b %Y %H:%M:%S GMT')
        return max(0, (retry_date - datetime.utcnow()).total_seconds())
    except ValueError:
        return None
`

def adaptive_rate_limit_backoff(provider: str, attempt: int) -> float:
    """Provider感知的自适应退避"""
    # Z.AI特定的退避策略
    if provider == 'zai_coding':
        delays = [30, 60, 90, 120]  # 30s->60s->90s->120s
        return delays[min(attempt, len(delays) - 1)]
    
    # 默认退避策略
    return jittered_backoff(attempt)

## 预算管理

### IterationBudget类

系统通过迭代预算控制Agent的执行：

`python
class IterationBudget:
    """线程安全的迭代计数器"""
    
    def __init__(self, max_total: int):
        self.max_total = max_total  # 默认500
        self._used = 0
        self._lock = threading.Lock()
    
    def consume(self) -> bool:
        """消耗一次迭代"""
        with self._lock:
            if self._used >= self.max_total:
                return False
            self._used += 1
            return True
    
    def refund(self) -> None:
        """退还一次迭代（用于execute_code）"""
        with self._lock:
            if self._used > 0:
                self._used -= 1
`

## 最佳实践

### 重试策略选择

`python
# 1. 网络错误：指数退避
if isinstance(error, NetworkError):
    delay = jittered_backoff(attempt)

# 2. 速率限制：使用Retry-After
elif isinstance(error, RateLimitError):
    delay = parse_retry_after_seconds(response) or jittered_backoff(attempt)

# 3. 服务器错误：固定延迟
elif isinstance(error, ServerError):
    delay = 5.0

# 4. 认证错误：不重试
elif isinstance(error, AuthError):
    raise error
`

### 监控指标

1. **重试率**: 重试请求占总请求的比例
2. **平均重试次数**: 每个请求的平均重试次数
3. **退避时间分布**: 退避时间的统计分布
4. **成功率提升**: 重试带来的成功率提升

### 故障排除

1. **重试风暴**: 检查退避算法是否添加抖动
2. **预算耗尽**: 调整max_iterations配置
3. **超时频繁**: 增加timeout配置或优化请求
4. **惊群效应**: 确保使用jittered_backoff
