## 简介
本文档提供SparkiiDesktop的负载均衡器配置指南，支持Nginx、HAProxy和云服务商负载均衡器，确保高可用性和可扩展性。

## Nginx配置

### 基本配置
```nginx
upstream sparkii_backend {
    least_conn;
    server 127.0.0.1:8080 weight=3;
    server 127.0.0.1:8081 weight=2;
    server 127.0.0.1:8082 backup;
}

server {
    listen 443 ssl;
    server_name sparkii.example.com;

    ssl_certificate /etc/ssl/cert.pem;
    ssl_certificate_key /etc/ssl/key.pem;

    location / {
        proxy_pass http://sparkii_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /ws {
        proxy_pass http://sparkii_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

## HAProxy配置

### 配置示例
```
global
    maxconn 4096

defaults
    mode http
    timeout connect 5000ms
    timeout client 50000ms
    timeout server 50000ms

frontend sparkii_front
    bind *:443 ssl crt /etc/ssl/sparkii.pem
    default_backend sparkii_back

backend sparkii_back
    balance leastconn
    option httpchk GET /health
    server web1 127.0.0.1:8080 check
    server web2 127.0.0.1:8081 check
    server web3 127.0.0.1:8082 check backup
```

## WebSocket支持

### 配置要点
- 启用HTTP/1.1 Upgrade
- 设置Connection: upgrade
- 配置长连接超时
- 支持二进制帧传输

### Nginx WebSocket配置
```nginx
location /ws {
    proxy_pass http://backend;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_read_timeout 3600s;
    proxy_send_timeout 3600s;
}
```

## 健康检查

### 检查端点
```
GET /health
Response: {"status": "ok", "version": "1.0.0"}
```

### 检查配置
- **间隔**：每10秒检查一次
- **超时**：5秒无响应判定失败
- **重试**：连续3次失败后移除
- **恢复**：连续2次成功后恢复

## 结论
合理配置负载均衡器是生产环境部署的关键。根据实际流量和可用性要求，选择合适的负载均衡器和配置参数，确保系统稳定运行。
