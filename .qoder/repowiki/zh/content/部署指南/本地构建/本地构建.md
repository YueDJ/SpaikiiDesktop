## 简介

## 构建环境要求

### 必需工具
- Python 3.10+
- Node.js 18+
- uv
- Git

## 容器化构建
`dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY . .
RUN pip install -e .
EXPOSE 8080
CMD ["python", "-m", "sparkii_agent"]
`

## 故障排查指南
- 依赖冲突: 使用 uv pip check
- 编译错误: 检查 TypeScript 版本
- 打包失败: 检查 PyInstaller 配置
