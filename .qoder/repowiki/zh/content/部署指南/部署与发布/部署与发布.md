## 版本管理

### 语义化版本

系统遵循语义化版本规范：

- **主版本号**: 不兼容的API变更
- **次版本号**: 向后兼容的功能新增
- **修订号**: 向后兼容的问题修复

### 版本更新

`python
# scripts/release.py
def bump_version(version: str, level: str) -> str:
    """更新版本号"""
    major, minor, patch = map(int, version.split('.'))
    
    if level == "major":
        return f"{major + 1}.0.0"
    elif level == "minor":
        return f"{major}.{minor + 1}.0"
    else:
        return f"{major}.{minor}.{patch + 1}"
`

## 发布流程

### 自动化发布

`python
# scripts/release.py
def release(version: str, level: str):
    """执行发布流程"""
    # 1. 更新版本号
    new_version = bump_version(version, level)
    update_version_in_pyproject(new_version)
    
    # 2. 生成变更日志
    generate_changelog(new_version)
    
    # 3. 运行测试
    run_tests()
    
    # 4. 构建包
    build_package()
    
    # 5. 创建Git标签
    create_git_tag(new_version)
    
    # 6. 推送到仓库
    push_to_remote()
    
    # 7. 发布到PyPI
    publish_to_pypi()
`

## 容器化部署

### Dockerfile

`dockerfile
FROM python:3.13-slim

WORKDIR /app

# 安装依赖
COPY pyproject.toml uv.lock ./
RUN pip install uv && uv sync --locked

# 复制代码
COPY . .

# 运行
CMD ["sparkii"]
`

### Docker Compose

`yaml
version: '3.8'
services:
  sparkii:
    build: .
    ports:
      - "8000:8000"
    environment:
      - OPENAI_API_KEY=
    volumes:
      - ./data:/app/data
`

### 多阶段构建

`dockerfile
# 构建阶段
FROM python:3.13-slim as builder
WORKDIR /app
COPY pyproject.toml uv.lock ./
RUN pip install uv && uv sync --locked --no-dev

# 运行阶段
FROM python:3.13-slim
WORKDIR /app
COPY --from=builder /app/.venv /app/.venv
COPY . .
CMD [".venv/bin/sparkii"]
`

## 回滚策略

### 版本回滚

`ash
# 回滚到指定版本
git checkout v0.19.0
uv sync --locked
systemctl restart sparkii
`

### 数据回滚

`ash
# 备份当前数据
cp -r /var/lib/sparkii /var/lib/sparkii.backup

# 恢复旧版本数据
cp -r /var/lib/sparkii.v0.19.0/* /var/lib/sparkii/
